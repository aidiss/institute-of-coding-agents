# Releases — 2026-05-06

## Models

### OpenAI on AWS Bedrock — GPT-5.5 / GPT-5.4 (Limited Preview)

- **OpenAI models on Amazon Bedrock** — Limited preview (announced April 28, 2026 at *What's Next with AWS, 2026*; AWS Weekly Roundup featured the launch May 4). Brings GPT-5.5 and GPT-5.4 into the Bedrock API surface alongside Anthropic, Meta, Mistral, Cohere, and Amazon's own Nova models. Inherits Bedrock's enterprise controls — IAM, AWS PrivateLink, guardrails, encryption, CloudTrail.
- **Strategic context**: launch occurred ~24 hours after Microsoft and OpenAI's exclusive cloud arrangement formally expired. First time AWS customers can call OpenAI frontier models through the same Bedrock services they already use for fine-tuning and orchestration.
- Pricing not yet published for the Bedrock surface; expected to track OpenAI direct-API rates with AWS-side handling fees.

### Gemini 3.1 Flash-Lite — Pricing reminder (already GA)

- Already-released Gemini 3.1 Flash-Lite (preview rolled out March 3, 2026; broadly available since April) priced at **$0.25 / $1.50 per M tokens**. 2.5× faster Time-to-First-Token and 45% faster output speed vs Gemini 2.5 Flash. Adjustable thinking levels in AI Studio and Vertex AI. Continues to expand cost-efficient routing footprint in this week's product launches (Augment Prism notably pulls Flash-Lite into its routed mix).

## Products

### OpenAI Codex on Amazon Bedrock — Limited Preview

- **Codex on Amazon Bedrock** — Limited preview (announced April 28, AWS Weekly Roundup May 4, 2026). OpenAI's coding agent surfaced inside AWS environments: authentication via AWS credentials, inference through Bedrock, usage applies to AWS cloud commitments.
- Available through the **Codex CLI**, the **Codex desktop app**, and the **VS Code extension** — same client surface as standalone Codex, repointed at Bedrock for inference.
- Targets enterprises that want Codex's coding agent without standing up a separate OpenAI billing relationship.

### Amazon Bedrock Managed Agents (powered by OpenAI) — Limited Preview

- **Bedrock Managed Agents** — Limited preview (announced April 28, 2026). Production-ready agent runtime built on the OpenAI agent harness, with frontier OpenAI models, identity, memory, logging, and governance baked in.
- Positioned for multi-step workflows that need durable context and tool access; complements the existing AgentCore platform rather than replacing it.

### AWS Bedrock AgentCore — Observability Updates

- AgentCore now ships **recommendations**, **batch evaluations**, and **A/B tests** to close the observe-evaluate-improve loop for production agents. Available alongside the OpenAI announcements, so customers can run OpenAI-powered agents and Anthropic-powered agents through the same evaluation harness.

### Cognition — Devin 2.2

- **Devin 2.2** — GA (released May 1, 2026). Cumulative release covering hundreds of improvements over recent weeks. Headline changes:
  - **3× faster session startup**, so agent output appears within seconds rather than minutes.
  - **Full Desktop Testing**: Devin can now QA its own PR end-to-end — runs the app in a Linux desktop, drives it via computer use, and returns an edited recording of the test. First mainstream coding agent to ship desktop-app E2E testing as a default capability rather than a beta toggle.
  - **Stacked Review Permissions**: enterprise admins can assign tiered PR-review access — manual-only, auto-on-creation, or auto-on-every-push — per organization member.
  - **Per-product Agent Compute Unit analytics** in the v3 analytics API.
  - Smoother Slack and Linear integrations for starting sessions without context-switching.

### Augment Code — Prism Router + Transcript Persistence

- **Prism** — GA in May 2026. New option in Augment's model picker that routes each turn to whichever model fits the work; Augment claims it matches the best individual frontier model on quality at **20–30% lower per-task cost**.
- **Transcript Persistence** (May 3, 2026 release): new `keepTranscriptOnNewSession` setting preserves conversation history when starting a new TUI session.
- Same release added `auggie context stats` for token/context usage, `--json` flag on `auggie account status`, terminal-title-control, and Git-based plugin sourcing for the marketplace.

### Roo Code — Sunset Notice

- **Roo Code Extension, Cloud, and Router** — sunsetting **May 15, 2026** (announced April 20). The Roo team is pivoting to **Roomote**, a cloud-only autonomous agent that drives Slack, GitHub, and Linear end-to-end without requiring IDE interaction.
- **Roomote**: beta opens to the first 200 waitlist users in May 2026; full launch July 6, 2026. Pricing **$20/mo + $5/hr (Pro)** and **$99/mo + $5/hr (Team)** with a 14-day free trial.
- Roo Code's official hand-off recommendation for IDE users is **Cline** (Cline absorbed much of Roo's open-source work) or **Continue**.

## Key Themes

- **Cloud lock-in is breaking**: GPT-5.5 / GPT-5.4 / Codex on AWS Bedrock is the most consequential platform release of the week. For two years, AWS customers had to bridge to Azure or stand up a separate OpenAI account to use GPT-5-class models; that gap closed within 24 hours of the Microsoft–OpenAI exclusivity expiry. Anthropic remains the default Bedrock frontier brand, but no longer the only one.
- **Agent QA as a default capability**: Devin 2.2's Full Desktop Testing makes computer-use-driven E2E verification a baseline feature rather than a research demo. Expect Cursor, Windsurf, and Claude Code to follow within the quarter — especially Cursor, which already has a Design Mode primitive that points in this direction.
- **The IDE-extension tier is consolidating**: Roo Code's exit, with Cline as the named heir, leaves Cline / Continue as the two serious open-source VS Code agents. The Roo team's pivot to a cloud-only agent (Roomote) is itself a thesis statement — that the IDE plugin is no longer where the value sits.
- **Routing-as-a-product**: Augment's Prism is the latest entry in a routing-router category that now includes Windsurf's Adaptive model selector and several startup-tier products. Claim: 20–30% cost reduction at parity quality. Worth tracking whether independent benchmarks corroborate that gap.
