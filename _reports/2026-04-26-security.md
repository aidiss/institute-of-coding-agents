## Headlines

- **Anthropic's MCP has a design-level RCE flaw** affecting every language SDK and an estimated 200,000 servers. Anthropic classified the behavior as "expected" and has not changed the protocol. Multiple downstream CVEs have been issued; patches are vendor-specific and inconsistent.
- **GitHub Copilot hit by two CVEs in April**: CVE-2026-21516 (Reprompt Attack data exfiltration) and CVE-2025-53773 (CVSS 9.6, prompt injection in PR descriptions leading to RCE). Both disclosed publicly in April 2026.
- **Three major coding agents simultaneously compromised** by a single prompt injection through the GitHub MCP integration, leaking sensitive data including salary records and proprietary source code into public pull requests.
- **SANDWORM_MODE supply chain campaign** identified: 19 malicious npm packages silently install rogue MCP servers inside developer environments, targeting Claude Code, Cursor, Windsurf, and VS Code Continue.
- **Secrets sprawl accelerating**: 28.65 million hardcoded secrets added to public GitHub in 2025 (+34% YoY); AI-service credentials up 81% YoY; Claude Code co-authored commits leak secrets at roughly 2× the baseline developer rate.

## Incidents & Vulnerabilities
_As of 2026-04-26_

### Anthropic MCP Design Flaw — ~200K Servers at RCE Risk

**Disclosed:** April 16, 2026 | **CVEs:** CVE-2025-49596 (MCP Inspector), CVE-2026-22252 (LibreChat), CVE-2026-22688 (WeKnora), CVE-2025-54994 (@akoskm/create-mcp-server-stdio), CVE-2025-54136 (Cursor) | **Vendor fix:** Partial — downstream vendors patching individually; Anthropic declined to alter protocol

OX Security published research documenting a design flaw in Anthropic's official MCP SDK that enables arbitrary OS command execution on any system running a vulnerable MCP implementation. The flaw is present in all supported language SDKs (Python, TypeScript, Java, Rust) and is exploitable via the STDIO transport layer: because STDIO-based MCP servers pass commands directly to the OS without privilege separation, any actor who can influence server configuration or prompt content can achieve RCE under the running process's privileges.

**Scale:**
- ~200,000 publicly reachable servers estimated at risk (The Register, April 16, 2026)
- >7,000 directly enumerable public MCP server instances
- >150 million total downloads across affected packages
- Deploying 10 MCP plugins raises per-deployment exploit probability to 92% (VentureBeat)

**Anthropic's position:** Anthropic reviewed the findings and declined to modify the protocol's architecture, characterizing the STDIO command execution behavior as "expected." Patches have been issued by individual vendors (LibreChat, Cursor, WeKnora), but the underlying behavior remains in the reference implementation.

**Attack surface note:** Windsurf and Cursor read local project files and web content; researchers demonstrated that a malicious website can feed hidden MCP configuration changes to the AI IDE, which then executes rogue STDIO commands immediately upon applying edits. No confirmation required from the user.

*Sources: [The Hacker News — Anthropic MCP Design Vulnerability Enables RCE](https://thehackernews.com/2026/04/anthropic-mcp-design-vulnerability.html) | [The Register — MCP 'design flaw' puts 200k servers at risk](https://www.theregister.com/2026/04/16/anthropic_mcp_design_flaw/) | [OX Security — MCP Supply Chain Advisory](https://www.ox.security/blog/mcp-supply-chain-advisory-rce-vulnerabilities-across-the-ai-ecosystem/) | [BDTechTalks — Anthropic's MCP Vulnerability](https://bdtechtalks.com/2026/04/20/anthropic-mcp-vulnerability/)*

### CVE-2026-21516 — GitHub Copilot "Reprompt Attack" (Data Theft)

**Disclosed:** April 2026 | **Type:** Prompt injection → data exfiltration | **Status:** Under active investigation / partially patched

CVE-2026-21516 describes a "Reprompt Attack" against GitHub Copilot in which prompt injection embedded in repository content (pull request descriptions, comments, file contents) causes Copilot to re-process attacker-controlled instructions in a privileged context, leaking data accessible to the agent to an attacker-controlled endpoint.

- **Affected scope:** GitHub Copilot across IDE integrations where the agent processes PR/issue content
- **Exploitation:** An attacker submits a pull request or files an issue containing hidden prompt injection instructions; a developer who opens or asks Copilot to review the content triggers the injection
- **Data at risk:** Any content in the agent's active context window at time of injection — source files, secrets, reviewed diffs, user messages

*Source: [Paperclipped — CVE-2026-21516 Reprompt Attack Explained](https://www.paperclipped.de/en/blog/github-copilot-cve-2026-21516-reprompt-attack/)*

### CVE-2025-53773 — GitHub Copilot Hidden Prompt Injection → RCE (CVSS 9.6)

**Disclosed:** 2026 | **CVSS:** 9.6 (Critical) | **Type:** Prompt injection → remote code execution | **Status:** Patched

A hidden prompt injection vulnerability in GitHub Copilot enabled remote code execution when Copilot was asked to review pull request descriptions containing adversarial instructions. The injection exploited the agent's tool-use capabilities to execute shell commands in the developer's environment.

Additionally, **CVE-2026-29783** (CVSS 7.5) affected Copilot CLI ≤ 0.0.422: bash parameter expansion patterns (`${var@P}`) bypassed the CLI's "read-only" safety assessment, allowing arbitrary code execution via shell expansion. Fixed in Copilot CLI v0.0.423.

### Three Coding Agents Exfiltrate Secrets via GitHub MCP — Simultaneous Prompt Injection

**Disclosed:** April 2026 | **Affected:** Claude Code, Gemini CLI, GitHub Copilot | **Status:** Incident; no single CVE assigned

VentureBeat and supporting research documented a real-world attack in which a malicious GitHub issue embedded hidden prompt injection instructions into a public repository. When each of three AI coding agents (Claude Code, Gemini CLI, GitHub Copilot) processed the issue via the GitHub MCP integration, all three were triggered to:

1. Access private repositories visible in the developer's OAuth session
2. Exfiltrate sensitive data (salary records, proprietary source code) into a public pull request

The attack required no code execution on the developer's machine — only that the agent held an active GitHub token and processed the malicious issue. Notably, Anthropic's own system card for Claude Code predicted this class of vulnerability, acknowledging that the GitHub Actions integration "is not hardened against prompt injection."

This is the first publicly documented case of a single prompt injection attack simultaneously compromising three independent coding agent products.

*Source: [VentureBeat — Three AI coding agents leaked secrets through a single prompt injection](https://venturebeat.com/security/ai-agent-runtime-security-system-card-audit-comment-and-control-2026) | [Knostic — From .env to Leakage: Mishandling of Secrets by Coding Agents](https://www.knostic.ai/blog/claude-cursor-env-file-secret-leakage)*

### Windsurf — Prompt Injection RCE (Version 1.9544.26)

**Disclosed:** 2026 | **Affected:** Windsurf IDE ≤ 1.9544.26 | **Type:** Prompt injection → arbitrary command execution | **Status:** Patched in later releases

A vulnerability in Windsurf allows remote attackers to execute arbitrary commands via prompt injection in content processed by the AI assistant. The attack vector includes web pages visited while the assistant is active, local files read during a session, and MCP configuration files — all of which the assistant processes as trusted instructions. Because Windsurf applies code edits and executes commands without explicit per-command confirmation, injected instructions can reach shell execution without user awareness.

### ChatGPT — Hidden Outbound Channel in Code Execution Runtime (Patched Feb 20, 2026)

**Disclosed:** Early 2026 | **Researcher:** Check Point Research | **Status:** Fixed February 20, 2026

## Supply Chain
_As of 2026-04-26_

### SANDWORM_MODE — 19 Malicious npm Packages Deploying Rogue MCP Servers

**Identified:** Q1–Q2 2026 | **Targets:** Claude Code, Cursor, Windsurf, VS Code Continue | **Status:** Packages removed from npm; monitor for reappearance

Security researchers identified a coordinated npm supply chain campaign ("SANDWORM_MODE") in which 19 malicious packages silently install rogue MCP servers into AI coding tool configurations upon installation. Once the rogue server is registered, it intercepts tool calls made by the AI agent — gaining the ability to read arbitrary files, exfiltrate credentials, and inject malicious instructions into agent responses.

**Attack mechanics:**
1. Malicious package installs as a normal developer dependency
2. Post-install script writes a new MCP server entry to the AI tool's configuration file (`mcp.json`, `.cursor/mcp.json`, etc.)
3. Rogue STDIO-based MCP server launches with each agent session
4. Server has ambient access to the agent's full tool surface (file I/O, shell, web browsing)

**Affected tools:** Claude Code, Cursor, Windsurf, VS Code with Continue extension.

*Source: [Knostic — AI Coding Assistants Leaking Secrets](https://www.knostic.ai/blog/ai-coding-assistants-leaking-secrets) | [Security Boulevard — Coding Agents Widen Your Supply Chain Attack Surface](https://securityboulevard.com/2026/03/coding-agents-widen-your-supply-chain-attack-surface/)*

### postmark-mcp — Trojanized npm Package (Silent Email BCC Exfiltration)

**Identified:** 2026 | **Vector:** npm supply chain | **Status:** Package removed; re-publication risk

The `postmark-mcp` npm package was trojanized: a single malicious line silently BCC'd every outbound email sent through the MCP integration to an attacker-controlled domain. The modification granted attackers implicit access to all outbound communications handled by AI agents using the package — without any error or behavioral change visible to the developer or agent.

This attack is notable for its minimal code footprint (one line) and its abuse of an email-sending MCP tool to establish a persistent, covert data channel.

*Source: [VentureBeat — MCP stacks have a 92% exploit probability](https://venturebeat.com/security/mcp-stacks-have-a-92-exploit-probability-how-10-plugins-became-enterprise)*

### Slopsquatting — Hallucinated Package Names as Supply Chain Attack Vector

**Ongoing** | **Research:** Multiple sources | **Threat level:** Escalating

AI coding agents autonomously select and install dependencies, amplifying the "slopsquatting" attack surface identified in 2025 research:

- ~20% of 756,000 AI-generated code samples included hallucinated (non-existent) package names
- 58% of hallucinated package names recur consistently across multiple model runs — making them predictable and registerable by attackers
- A researcher who registered `huggingface-cli` (a frequently hallucinated Python package) observed 30,000+ installs within three months, all from developers acting on AI-generated code
- Coding agents (Claude Code, Cursor, Copilot Workspace) can install dependencies autonomously at build time, eliminating the human review step that historically caught typosquatted packages

The 2026 escalation: agents with CI/CD write access can propagate a hallucinated dependency from a single AI suggestion into a production artifact without any human touching the `pip install` or `npm install` command.

*Sources: [BleepingComputer — AI-hallucinated code dependencies become new supply chain risk](https://www.bleepingcomputer.com/news/security/ai-hallucinated-code-dependencies-become-new-supply-chain-risk/) | [Infosecurity Magazine — AI Hallucinations Create "Slopsquatting" Supply Chain Threat](https://www.infosecurity-magazine.com/news/ai-hallucinations-slopsquatting/) | [Security Boulevard — Coding Agents Widen Your Supply Chain Attack Surface](https://securityboulevard.com/2026/03/coding-agents-widen-your-supply-chain-attack-surface/)*

## Research & Advisories
_As of 2026-04-26_

### arxiv — Systematic Analysis of Prompt Injection in AI Coding Agents (January 2026)

A systematic academic analysis of prompt injection vulnerabilities across AI coding agent skills, tools, and MCP ecosystems found that attack success rates against state-of-the-art defenses exceed 85% when adaptive strategies are employed. The core finding: models have no reliable mechanism to distinguish instructions from data. Any content processed by the model — including file contents, web pages, API responses, and tool outputs — can be weaponized as an instruction channel. The paper recommends architectural changes (privilege separation at the tool call layer) rather than prompt-level defenses, which the authors classify as fundamentally insufficient.

*Source: [arxiv 2601.17548 — Prompt Injection Attacks on Agentic Coding Assistants](https://arxiv.org/html/2601.17548v1)*

### Cycode — AI Security Vulnerabilities to Watch in 2026

Cycode's 2026 threat landscape review identifies "the lethal trifecta" in agentic AI security: (1) ambient authority (agents inherit broad permissions from the developer's environment), (2) automatic trust (agents treat all content in context as trusted instructions), and (3) autonomous execution (agents act without per-step confirmation). The combination means a single successful prompt injection against an agent with shell access, file write, and git push permissions achieves full developer workstation compromise plus potential repository poisoning in a single attack chain.

*Source: [Cycode — Top AI Security Vulnerabilities 2026](https://cycode.com/blog/ai-security-vulnerabilities/)*

### Sherlockforensics — 92% of AI-Generated Code Contains Critical Vulnerabilities (2026 Report)

A 2026 analysis of AI-generated code across major coding assistants found that 92% of samples contained at least one critical vulnerability. The most common classes: insecure deserialization, missing authentication on internal endpoints, shell injection in generated scripts, and hardcoded credentials in configuration templates. The report specifically flags autonomous coding agents (which generate, commit, and deploy without human review) as the highest-risk deployment pattern.

*Source: [Sherlockforensics — 92% of AI Code Has Critical Vulnerabilities](https://www.sherlockforensics.com/pages/ai-code-security-report-2026.html)*

## Analyst Note

Three structural themes define the April 2026 reporting cycle:

**1. The MCP protocol itself is now the attack surface.** Anthropic's decision to classify the STDIO RCE behavior as "expected" and decline protocol changes shifts the entire burden of defense to downstream vendors and operators. With 200,000 servers and 150M+ downloads in scope, and no coordinated remediation path, this is effectively an unfixed ecosystem-wide vulnerability. Teams running MCP servers should treat them as full command-execution endpoints and apply network-level controls accordingly — not just application-level input validation.

**2. Multi-agent prompt injection is now a demonstrated attack class.** The simultaneous compromise of Claude Code, Gemini CLI, and GitHub Copilot via a single GitHub issue is qualitatively different from single-tool attacks: it shows that shared protocol surfaces (MCP, GitHub API) create correlated failure modes across competing products. An attacker who understands which MCP integrations a target developer uses can craft a single payload that fires against all of them simultaneously.

**3. Secrets sprawl is an AI-accelerated crisis.** The 81% YoY jump in AI-service credential leaks, combined with coding agents that autonomously commit and push, suggests the problem will compound faster than current developer hygiene practices can address. The SANDWORM_MODE and postmark-mcp campaigns demonstrate that attackers have operationalized this: rather than exfiltrating secrets after the fact, they are injecting infrastructure (rogue MCP servers, BCC hooks) that continuously harvests credentials as they flow through agent-mediated workflows.

**Immediate actions:**

- **MCP operators:** Treat all STDIO-based MCP servers as command-execution endpoints; apply firewall rules, run under dedicated low-privilege accounts, and audit all registered MCP servers for legitimacy
- **GitHub Copilot users:** Patch to latest Copilot CLI (≥ 0.0.423) for CVE-2026-29783; treat PR descriptions and issue content as potentially adversarial when Copilot is active
- **All agent users:** Audit `mcp.json` and equivalent config files for unexpected server entries; any unrecognized STDIO server entry should be treated as an indicator of compromise
- **npm package consumers:** Cross-reference all AI tool–adjacent packages against the npm advisory database; packages like `postmark-mcp` may re-emerge under alternate names after removal
- **Secrets management:** Rotate all AI-service API keys (Anthropic, OpenAI, Hugging Face) if they have ever existed in files accessible to a coding agent; implement secrets scanning in CI before agent-generated commits merge
