# Security Brief — 2026-04-30

Track of vulnerabilities, supply chain attacks, and safety incidents affecting AI coding agents.

---

## Incidents & Vulnerabilities

### Comment and Control / RoguePilot — Prompt Injection Leaks Secrets from Three Coding Agents
**Status: Disclosed / Vendor responses ongoing**

A runtime security audit published this week demonstrated prompt injection attacks successfully exfiltrating secrets from three mainstream AI coding agents. Two exploits were documented in detail:

- **Comment and Control:** A hidden instruction embedded in a source file comment caused Claude Code to exfiltrate the developer's API key. Anthropic's own system card acknowledged the tool is "not hardened against prompt injection." No CVE assigned; Anthropic's response addressed documentation warnings rather than code changes.
- **RoguePilot:** A passive prompt injection delivered via a GitHub Issue containing a hidden HTML comment caused a JetBrains-based coding agent to steal the `GITHUB_TOKEN` and perform a full repository takeover via Codespaces. The attacker needed only to file an issue; no further developer interaction was required.

The root cause across both is architectural: AI models have no reliable mechanism to distinguish between trusted instructions and adversarial content embedded in the data they process.

### CVE-2026-21516 — GitHub Copilot for JetBrains Command Injection (CVSS 8.8)
**Status: Disclosed / Patched (v1.5.63, February 10, 2026)**

The Copilot JetBrains plugin failed to sanitize shell metacharacters (`;`, `|`, backticks, `$(...)`) in model-generated code suggestions before passing them to the shell. An attacker can inject arbitrary OS commands that execute with the developer's permissions.

- **Affected versions:** GitHub Copilot for JetBrains 1.0.0–1.5.62
- **Data at risk:** SSH keys, API tokens, CI/CD credentials, cloud provider keys, signing certificates — sufficient for downstream supply-chain attacks
- **Fix:** Update to v1.5.63. No confirmed exploitation in the wild before patch.
- **Related CVEs:**
  - **CVE-2026-21523** (CVSS 8.0) — TOCTOU race condition in Copilot for VS Code
  - **CVE-2026-29783** (CVSS 7.5) — Shell expansion bypass in Copilot CLI (bash `${var@P}` patterns bypass safety assessment); fixed in CLI v0.0.423

### Microsoft Copilot Reprompt / Data-Exfiltration Attack
**Status: Disclosed / Patched (January 13–14, 2026)**

A separate vulnerability in Microsoft Copilot (not the IDE plugin) enabled one-click exfiltration of usernames, calendar data, and location information through URL parameter injection combined with staged server-based commands that bypassed guardrails. Patched within 24 hours of disclosure; no CVE currently assigned.

### IDEsaster Research — 30+ Flaws Across 10 AI Coding Tools (24 CVEs Assigned)
**Status: Disclosed / Vendor patches vary**

Researchers published findings covering more than 30 vulnerabilities across GitHub Copilot, Cursor, Windsurf, Kiro.dev, Zed.dev, Roo Code, JetBrains Junie, Cline, Gemini CLI, and Claude Code. Notable specifics:

- **CVE-2025-59944 (Cursor):** Case-sensitivity bypass enabling persistent RCE across IDE restarts via MCP configuration files.
- **CamoLeak (GitHub Copilot, CVSS 9.6):** Critical prompt injection using invisible Unicode characters to silently exfiltrate code without triggering content filters.
- **CVE-2025-62449 / CVE-2025-62453 (GitHub Copilot):** Path traversal and code injection in the VS Code extension.
- AWS issued advisory **AWS-2025-019** in response to findings affecting Kiro.dev.

Claude Code's vendor response was documentation-only (security warnings); no code-level mitigations were introduced for the reported issues.

### Google Antigravity — RCE via Prompt Injection and Sandbox Escape
**Status: Disclosed / Patched**

A critical prompt injection vulnerability in Google's Antigravity agentic IDE allowed attackers to craft inputs that escaped the sandbox and achieved remote code execution on the developer's machine. Google patched the flaw following a researcher proof-of-concept. No CVE or CVSS score has been published; timeline details remain limited.

## Supply Chain

### CanisterSprawl — Self-Propagating npm Worm Targets Developer Credentials
**Status: Disclosed (April 22, 2026) / Affected packages unpublished**

A self-propagating supply-chain worm was discovered spreading across npm packages. Unlike previous attacks, CanisterSprawl does not stop at credential theft — it uses stolen npm tokens to push poisoned versions of additional packages, enabling autonomous lateral spread across the ecosystem.

**Confirmed affected packages (malicious version ranges):**
- `@automagik/genie` (4.260421.33–4.260421.40)
- `@fairwords/loopback-connector-es` (1.4.3–1.4.4)
- `@fairwords/websocket` (1.0.38–1.0.39)
- `@openwebconcept/design-tokens` (1.0.1–1.0.3)
- `@openwebconcept/theme-owc` (1.0.1–1.0.3)
- `pgserve` (1.1.11–1.1.14)

**Data harvested:** `.npmrc` tokens, SSH keys, AWS/GCP/Azure/Kubernetes configs, Terraform state, database passwords, `.env` files, browser-saved credentials, cryptocurrency wallets.

**Infrastructure:** Exfiltrates to `telemetry.api-monitor[.]com` (HTTPS) and an ICP canister for resilience against takedowns. The worm also includes PyPI propagation logic via Python `.pth` payloads, enabling cross-ecosystem spread.

No CVE assigned at time of writing.

### SAP-Related npm Packages — Credential-Stealing Preinstall Hooks (April 29, 2026)
**Status: Disclosed / Packages under investigation**

Suspicious versions of SAP-related npm packages were published between 09:55–12:14 UTC on April 29, 2026. The poisoned packages introduce a `preinstall` hook in `package.json` that runs `setup.mjs` via the Bun JavaScript runtime. The payload harvests:

- Local developer credentials
- GitHub and npm tokens
- GitHub Actions secrets
- Cloud secrets (AWS, Azure, GCP, Kubernetes)

The malware also includes propagation logic targeting other packages in the developer's environment, following the same worm pattern as CanisterSprawl. Packages have been reported to npm; investigation is ongoing.

### MCP STDIO Design Flaw — Ongoing CVE Cascade
**Status: Protocol flaw unpatched / Individual projects remediating**
**CVEs: CVE-2025-49596, CVE-2026-22252, CVE-2026-22688, CVE-2025-54994, CVE-2025-54136, CVE-2026-30623, CVE-2026-30624, CVE-2026-40933, and others**

The systemic "by-design" flaw in Anthropic's MCP STDIO transport — which executes the supplied OS command before returning any error — continues to generate new CVEs weekly. Affected projects now include GPT Researcher, LiteLLM (patched), Agent Zero, Fay Framework, Bisheng (patched), Langchain-Chatchat, Upsonic, Windsurf, DocsGPT (patched), and Flowise. Exposure scale remains at 7,000+ public servers and 150 M+ downloads. Anthropic has declined architectural changes, characterising the behaviour as expected.

See also the comprehensive tracking database at [vulnerablemcp.info](https://vulnerablemcp.info/).

### Slopsquatting / AI-Hallucination Squatting — Active Exploitation Confirmed
**Status: Ongoing / No ecosystem-level fix**

The "slopsquatting" attack class — registering package names that AI coding tools hallucinate — continues to scale with agent adoption. Research demonstrates that ~20% of AI-generated code samples recommend non-existent packages, and 51% of hallucinated names are fully fabricated (not typo variants). A researcher-registered sentinel package (`huggingface-cli`, non-existent on PyPI) exceeded 30,000 downloads in three months, confirming active exploitation. Risk is compounding as autonomous coding agents (Cursor, Claude Code, Copilot Workspace) install packages without human review.

## Research & Advisories

### Georgia Tech Vibe Security Radar — 35 AI-Attributed CVEs in March 2026
Georgia Tech's Vibe Security Radar project confirmed 35 CVEs in March 2026 directly attributable to AI coding tool output, with 27 attributed to Claude Code, 4 to GitHub Copilot, 2 to Devin, and 1 each to Aether and Cursor. Researchers estimate the true ecosystem-wide count is 5–10× higher. Over the project's lifetime, 74 AI-attributed CVEs have been confirmed. The most common vulnerability classes introduced by AI tools are insecure defaults, missing input validation, and hardcoded credentials.

Reference: [labs.cloudsecurityalliance.org](https://labs.cloudsecurityalliance.org/research/csa-research-note-ai-generated-code-vulnerability-surge-2026/)

### Unit 42 — New Prompt Injection Attack Vectors via MCP Sampling
Palo Alto Networks Unit 42 published three proof-of-concept attacks exploiting the MCP sampling feature, demonstrating credential theft, data exfiltration, and lateral movement. The research illustrates that prompt injection in the MCP ecosystem is not limited to tool-call manipulation but extends to the sampling/inference path, widening the attack surface significantly.

Reference: [unit42.paloaltonetworks.com](https://unit42.paloaltonetworks.com/model-context-protocol-attack-vectors/)

### OX Security — MCP Supply Chain Advisory
OX Security published a coordinated advisory covering the MCP SDK flaw and its downstream impact on the AI supply chain, with remediation guidance: block public IP access to MCP servers, monitor tool invocations, run MCP services in sandboxes, treat external MCP configuration as untrusted, and only install MCP servers from verified sources.

Reference: [ox.security](https://www.ox.security/blog/mcp-supply-chain-advisory-rce-vulnerabilities-across-the-ai-ecosystem/)
