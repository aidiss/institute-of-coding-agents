# Security — 2026-04-23

## Incidents & Vulnerabilities

### Windsurf Zero-Click RCE via MCP Configuration Injection — CVE-2026-30615 (CVSS 8.0)
A prompt injection vulnerability in Windsurf 1.9544.26, disclosed April 15 2026, allows a remote attacker to execute arbitrary commands on a victim system without any user interaction beyond loading a crafted project. When the IDE processes attacker-controlled HTML or repository content, malicious instructions cause unauthorized modification of the local MCP configuration file and automatic registration of a rogue MCP STDIO server; the malicious server then receives command execution at startup. Classified as zero-click: simply opening an infected project suffices for compromise. Status: **disclosed, patch available in updated Windsurf builds; users on 1.9544.26 should update immediately**.

- CVE: **CVE-2026-30615** (CVSS v3 8.0)
- Affected: Windsurf 1.9544.26
- Fix: update to latest Windsurf release
- Source: [OX Security Advisory](https://www.ox.security/blog/mcp-supply-chain-advisory-rce-vulnerabilities-across-the-ai-ecosystem/), [DevOps Daily](https://devops-daily.com/posts/mcp-design-flaw-rce-supply-chain-risk)

### GitHub Copilot / VS Code RCE via Prompt Injection — CVE-2025-53773 (Critical, CVSS 9.6)
Disclosed June 2025 and patched in the August 2025 Microsoft Patch Tuesday, CVE-2025-53773 continues to attract active exploitation attempts as POC code circulates. The root cause is Copilot's ability to write arbitrary workspace files — including `.vscode/settings.json` — without requiring explicit user approval per write. Attackers embed hidden instructions (including zero-width Unicode characters) inside repository content, GitHub issues, or web pages fetched by the agent. The injected instructions enable `chat.tools.autoApprove: true` ("YOLO mode"), granting the agent unrestricted shell command execution. Self-propagating variants dubbed "ZombAI" embed the payload in new projects to recruit further developer machines. Status: **patched in August 2025 Patch Tuesday; unpatched installations remain at critical risk; wormable variants in circulation**.

- CVE: **CVE-2025-53773** (Critical, CVSS 9.6)
- Affected: GitHub Copilot in VS Code (all versions before August 2025 Patch Tuesday fix)
- Fix: apply Microsoft August 2025 security update
- Sources: [Embrace The Red](https://embracethered.com/blog/posts/2025/github-copilot-remote-code-execution-via-prompt-injection/), [Persistent Security (Part III — wormable variant)](https://www.persistent-security.net/post/part-iii-vscode-copilot-wormable-command-execution-via-prompt-injection), [NVD](https://nvd.nist.gov/vuln/detail/CVE-2025-53773), [Wiz Vuln DB](https://www.wiz.io/vulnerability-database/cve/cve-2025-53773)

### Flowise Authenticated RCE via MCP Adapters — CVE-2026-40933
An authenticated remote code execution vulnerability in Flowise's MCP adapter layer allows any logged-in user to execute operating system commands on the server. The adapter layer fails to sanitize command arguments passed through MCP tool calls. Status: **disclosed; fix tracked on GitLab advisories; update to a patched Flowise release**.

- CVE: **CVE-2026-40933**
- Affected: Flowise (versions using MCP adapter layer)
- Fix: see [GitLab advisory](https://advisories.gitlab.com/npm/flowise/CVE-2026-40933/)
- Source: [GitLab Security Advisories](https://advisories.gitlab.com/npm/flowise/CVE-2026-40933/)

### "Comment and Control" — Three Coding Agents Leak Secrets via Single Prompt Injection (April 2026)
VentureBeat reported a demonstration in which a single prompt injection payload embedded in a GitHub PR comment triggered secret exfiltration across three separate AI coding agents chained in a CI/CD pipeline. One vendor's published system card explicitly acknowledged that its agent "is not hardened against prompt injection" in the context of automated code review. No CVEs assigned; none of the three vendors have shipped targeted mitigations. Status: **disclosed, unpatched**.

- Source: [VentureBeat](https://venturebeat.com/security/ai-agent-runtime-security-system-card-audit-comment-and-control-2026), [Botmonster Tech](https://botmonster.com/posts/ai-coding-agent-insider-threat-prompt-injection-mcp-exploits/)

### Google Antigravity — Data Exfiltration and Persistent Backdoor via Prompt Injection
Researchers documented multiple vulnerabilities in Google Antigravity allowing indirect prompt injection attacks to result in data exfiltration and remote command execution. A separate attack path leverages a malicious trusted workspace to embed a persistent backdoor that executes arbitrary code on every subsequent application launch. Status: **disclosed; patch status not confirmed at time of writing**.

- Source: [Cycode AI Security Vulnerabilities 2026](https://cycode.com/blog/ai-security-vulnerabilities/)

## Supply Chain

### Anthropic MCP Architectural RCE — 14 CVEs, ~200,000 Servers at Risk (April 2026)
OX Security published a formal advisory documenting a systemic vulnerability baked into Anthropic's official MCP SDKs across all supported languages (Python, TypeScript, Java, Rust). The STDIO transport interface allows any caller to pass an OS command as the "server path"; if the command executes successfully and returns a valid handle, code execution is achieved before any error surface is visible. Anthropic confirmed the behaviour is intentional and declined to modify the SDK, stating that input sanitization is the developer's responsibility. The Register reported April 16 that Anthropic disputes ownership of the flaw. Fourteen CVEs have been filed against downstream implementations:

| CVE | Package / Product | Status |
|---|---|---|
| CVE-2025-49596 | MCP Inspector | Reported |
| CVE-2025-54136 | Cursor | Reported |
| CVE-2025-54994 | @akoskm/create-mcp-server-stdio | Reported |
| CVE-2026-22252 | LibreChat | Reported |
| CVE-2026-22688 | WeKnora | Reported |
| CVE-2026-30615 | Windsurf | Patched |
| CVE-2026-40933 | Flowise | Disclosed |

Estimated exposure: 7,000+ publicly accessible MCP servers; 150 million cumulative SDK downloads; up to 200,000 vulnerable instances. Status: **vendor-disputed at protocol level; per-package CVEs filed; mitigations: sandboxing, strict STDIO server allowlisting**.

- Sources: [OX Security](https://www.ox.security/blog/the-mother-of-all-ai-supply-chains-critical-systemic-vulnerability-at-the-core-of-the-mcp/), [The Hacker News](https://thehackernews.com/2026/04/anthropic-mcp-design-vulnerability.html), [The Register](https://www.theregister.com/2026/04/16/anthropic_mcp_design_flaw/), [Infosecurity Magazine](https://www.infosecurity-magazine.com/news/systemic-flaw-mcp-expose-150/), [Computing.co.uk](https://www.computing.co.uk/news/2026/security/flaw-in-anthropic-s-mcp-putting-200k-servers-at-risk)

### Slopsquatting — AI Package Hallucinations Weaponized at Scale (Ongoing)
A package hallucination rate of ~20% (across 576,000 Python and JavaScript AI-generated code samples) continues to fuel the slopsquatting attack class, where attackers pre-register hallucinated package names on PyPI and npm with malicious payloads. 58% of hallucinated names repeat consistently across model runs, making them practical targets. The huggingface-cli proof-of-concept registered by researcher Bar Lanyado surpassed 30,000 downloads including from Alibaba's public documentation. Autonomous coding agents (Cursor, Claude Code, GitHub Copilot Workspace) amplify the risk by issuing `pip install` / `npm install` without human review. Status: **no systemic fix; best practice is package name monitoring and dependency pinning**.

- Sources: [BleepingComputer](https://www.bleepingcomputer.com/news/security/ai-hallucinated-code-dependencies-become-new-supply-chain-risk/), [Infosecurity Magazine — Slopsquatting](https://www.infosecurity-magazine.com/news/ai-hallucinations-slopsquatting/), [Security Boulevard](https://securityboulevard.com/2026/03/coding-agents-widen-your-supply-chain-attack-surface/), [InstaTunnel Blog](https://instatunnel.my/blog/ai-hallucination-squatting-the-new-frontier-of-supply-chain-attacks)

### Automated Dependency Side-Loading via Malicious AI Extensions (February 2026)
A separate supply chain vector documented by InstaTunnel/Medium describes malicious IDE extensions that intercept dependency resolution subprocess calls made by coding agents and substitute trojanized packages at install time. Unlike slopsquatting this attack succeeds even when the LLM recommends a legitimately named, real package. No CVEs assigned; affected vendors notified. Status: **no broad mitigation deployed**.

- Source: [InstaTunnel / Medium](https://medium.com/@instatunnel/automated-dependency-side-loading-the-invisible-supply-chain-attack-via-ai-extensions-fe615eb03f19)

## Research & Advisories

### Systematic Analysis: All Major Coding Agents Vulnerable to Prompt Injection (January 2026)
A peer-reviewed systematic analysis covering 78 studies (arXiv 2601.17548) found that every tested coding agent — Claude Code, GitHub Copilot, Cursor — is vulnerable to prompt injection in their default configurations. Adaptive attack success rates exceed **85%**. The attack surface includes PR comments, repository files, web pages fetched by agents, issue bodies, and RAG document pipelines. The paper is cited in the Palo Alto Unit 42 MCP attack vector report and multiple active CVE advisories.

- Source: [arXiv 2601.17548](https://arxiv.org/html/2601.17548v1), [MDPI Information journal](https://www.mdpi.com/2078-2489/17/1/54)

### MCP Sampling — New Prompt Injection Attack Vectors (Unit 42)
Palo Alto Networks Unit 42 published a report identifying prompt injection attack vectors that exploit MCP's sampling interface, where a client asks a server to call back into the LLM on its behalf. A malicious MCP server can embed instructions in sampling requests that hijack the model's behavior during tool calls. This widens the attack surface beyond the tool-call and resource-read interfaces. Status: **no spec mitigation; awareness advisory**.

- Source: [Unit 42 / Palo Alto Networks](https://unit42.paloaltonetworks.com/model-context-protocol-attack-vectors/)

### "Lethal Trifecta" Threat Model for Coding Agents (2026)
Airia's security team articulated a compound threat model: **(1) prompt injection** provides initial access, **(2) excessive tool permissions** supply the privilege escalation surface, and **(3) insufficient output filtering** enables the exfiltration channel. The model argues that all three conditions are satisfied simultaneously in the majority of production coding agent deployments. Recommended mitigations: minimal tool scopes, output scanning at every boundary, and input sanitization.

- Source: [Airia](https://airia.com/ai-security-in-2026-prompt-injection-the-lethal-trifecta-and-how-to-defend/)

### OWASP: Prompt Injection Ranked #1 AI Application Threat (LLM01:2025)
OWASP maintains prompt injection as LLM01:2025, the top vulnerability in LLM-based applications. 73% of surveyed production AI deployments contain exploitable prompt injection paths; only 34.7% of organizations have deployed dedicated prompt injection defenses. OWASP's guidance and the growing CVE record both recommend treating every external input — user messages, repository content, fetched documents — as untrusted.

- Sources: [Securance](https://www.securance.com/blog/prompt-injection-the-owasp-1-ai-threat-in-2026), [Cycode](https://cycode.com/blog/ai-security-vulnerabilities/), [PromptInjection.wtf](https://promptinjection.wtf/)
