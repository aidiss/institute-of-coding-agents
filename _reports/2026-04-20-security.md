# Security — 2026-04-20

## Incidents & Vulnerabilities

### "Comment and Control" — Cross-Vendor Prompt Injection (Disclosed 2026-04-16)
Researchers at Johns Hopkins University (Zhengyu Liu, Gavin Zhong) and security engineer Aonan Guan disclosed a cross-vendor prompt injection attack that hijacks Anthropic's Claude Code Security Review, Google's Gemini CLI Action, and GitHub's Copilot Agent. Malicious instructions embedded in pull request titles, issue bodies, or comments exfiltrate `ANTHROPIC_API_KEY`, `GEMINI_API_KEY`, and `GITHUB_TOKEN` from CI runners. Anthropic classified it CVSS 9.4 Critical; no CVE has been assigned. Bug bounty payouts: Anthropic $100, Google $1,337, GitHub $500. Status: **disclosed, no patch at time of writing**.

- Sources: [SecurityWeek](https://www.securityweek.com/claude-code-gemini-cli-github-copilot-agents-vulnerable-to-prompt-injection-via-comments/), [researcher writeup](https://oddguan.com/blog/comment-and-control-prompt-injection-credential-theft-claude-code-gemini-cli-github-copilot/)

### CVE-2026-23744 — MCPJam Inspector RCE (CVSS 9.8)
MCPJam Inspector ≤ v1.4.2 bound its critical endpoint to `0.0.0.0` with no authentication. A single crafted HTTP request installs an arbitrary MCP server and executes code on the host with no user interaction. Status: **patch available in v1.4.3**.

### CVE-2025-53773 — GitHub Copilot PR Prompt Injection → RCE (CVSS 9.6)
Hidden prompt injection in pull request descriptions allowed remote code execution via GitHub Copilot's agent mode. Status: **patched**.

### CVE-2026-26118 — Azure MCP Server SSRF
Microsoft patched an SSRF vulnerability in the Azure MCP Server (2026-03-10) that allowed an authenticated attacker to escalate network privilege. Status: **patched**.

### CVE-2025-68143 / CVE-2025-68144 / CVE-2025-68145 — Anthropic mcp-server-git Chain
Three chained vulnerabilities in Anthropic's official `mcp-server-git`: path validation bypass, unrestricted `git_init`, and argument injection in `git_diff`. Combined with the Filesystem MCP server, they achieve full RCE via a malicious `.git/config` file. Status: **patched**.

### MCP Protocol Design Flaw — 200K Servers at Risk (2026-04-16)
Independent researchers disclosed a systemic design flaw in Anthropic's Model Context Protocol that exposes an estimated 200,000 deployed servers to complete takeover. Anthropic declined to modify the protocol architecture, describing the behavior as "expected." No CVE assigned. Status: **unresolved by vendor**.

- Source: [The Register](https://www.theregister.com/2026/04/16/anthropic_mcp_design_flaw/)

### Claude Code Source Leak → Infostealer Campaign (March–April 2026)
Anthropic inadvertently published internal source maps inside an npm package in late March 2026. Within 24 hours threat actors used the resulting media coverage to distribute fake "leaked Claude Code" downloads carrying credential-stealing payloads.

- Source: [Trend Micro](https://www.trendmicro.com/en_us/research/26/d/weaponizing-trust-claude-code-lures-and-github-release-payloads.html)

## Supply Chain

### LiteLLM PyPI Compromise — CVE-2026-33634 (2026-03-24)
Threat actor **TeamPCP** stole PyPI publishing credentials from LiteLLM's CI/CD pipeline by backdooring the `trivy-action` GitHub Action (tag `v0.69.4` repointed to a malicious release on 2026-03-19). The compromised `litellm==1.82.7` and `litellm==1.82.8` packages were live for ~40 minutes before PyPI quarantine. The payload — a `.pth` file (`litellm_init.pth`) — executes on every Python process startup, harvesting API keys, environment variables, and credentials. The same actor simultaneously trojanized Checkmarx tooling. CVE-2026-33634 covers the Trivy supply chain vector. CISA has issued an alert. Status: **packages quarantined; patched versions available**.

- Sources: [LiteLLM advisory](https://docs.litellm.ai/blog/security-update-march-2026), [Trend Micro](https://www.trendmicro.com/en_us/research/26/c/inside-litellm-supply-chain-compromise.html), [Snyk](https://snyk.io/blog/poisoned-security-scanner-backdooring-litellm/), [Sonatype](https://www.sonatype.com/blog/compromised-litellm-pypi-package-delivers-multi-stage-credential-stealer)

### Langflow RCE — CVE-2026-33017 (Actively Exploited)
CISA added Langflow to its Known Exploited Vulnerabilities catalog alongside the Trivy compromise. Status: **patch available; active exploitation confirmed**.

- Source: [Help Net Security](https://www.helpnetsecurity.com/2026/03/27/cve-2026-33017-cve-2026-33634-exploited/)

### Slopsquatting / AI Hallucinated Dependencies (Ongoing)
AI coding agents (Cursor, Claude Code, GitHub Copilot Workspace) autonomously install hallucinated package names. Researchers found that ~20% of 576,000 generated Python and JavaScript samples referenced non-existent packages; 43% of hallucinated package names were suggested consistently across repeated prompts — making them reliable targets for pre-registration by attackers. Security researcher Bar Lanyado registered `huggingface-cli` (a frequently hallucinated name) and observed 30,000+ downloads in three months. Autonomous agents accelerate risk because they execute `pip install` without human review.

- Sources: [BleepingComputer](https://www.bleepingcomputer.com/news/security/ai-hallucinated-code-dependencies-become-new-supply-chain-risk/), [Security Boulevard](https://securityboulevard.com/2026/03/coding-agents-widen-your-supply-chain-attack-surface/), [Capitol Tech University](https://www.captechu.edu/blog/ai-driven-threats-in-software-supply-chains)

## Research & Advisories

### Systematic Study: Every Major Coding Agent Vulnerable to Prompt Injection (January 2026)
A systematic review of 78 studies (published January 2026) confirmed that Claude Code, GitHub Copilot, and Cursor are all susceptible to prompt injection, with adaptive attack success rates exceeding **85%**. Indirect injection (malicious content in documents, emails, web pages, or database rows) now accounts for over 80% of documented enterprise attack attempts; direct injection is under 20%.

- Source: [MDPI Information journal](https://www.mdpi.com/2078-2489/17/1/54)

### OWASP: Prompt Injection Ranked #1 AI Threat for 2026
OWASP reports 73% of production AI deployments have exploitable prompt injection vulnerabilities. Prompt injection attacks surged 340% in 2026; only 34.7% of organizations have deployed dedicated defenses.

- Source: [Securance](https://www.securance.com/blog/prompt-injection-the-owasp-1-ai-threat-in-2026), [Airia](https://airia.com/ai-security-in-2026-prompt-injection-the-lethal-trifecta-and-how-to-defend/)

### Trail of Bits: Prompt Injection to RCE in AI Agents (October 2025)
Trail of Bits documented an attack chain from prompt injection to full remote code execution in agentic systems, establishing the canonical path now seen exploited in production.

- Source: [Trail of Bits blog](https://blog.trailofbits.com/2025/10/22/prompt-injection-to-rce-in-ai-agents/)

### Palo Alto Unit 42: MCP Sampling Attack Vectors
Unit 42 published analysis of how MCP's sampling mechanism (servers crafting prompts and requesting completions from the client LLM) enables prompt injection, hidden instruction injection, and subsequent tool execution manipulation.

- Source: [Palo Alto Unit 42](https://unit42.paloaltonetworks.com/model-context-protocol-attack-vectors/)

### VulnerableMCP.info — Community CVE Database for MCP
A community-maintained database tracking MCP-specific vulnerabilities now exists at [vulnerablemcp.info](https://vulnerablemcp.info/).

### RSAC 2026 Preview: Azure MCP RCE Demo
Research to be presented at RSAC 2026 demonstrates RCE in Microsoft's Azure MCP Server capable of compromising cloud environments via prompt injection escalation.
