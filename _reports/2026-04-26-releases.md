# Releases — 2026-04-26

## Models

### OpenAI — GPT-5.5

- **GPT-5.5** — GA (released April 23, 2026). Codenamed "Spud" internally. Positioned as a "faster, sharper thinker for fewer tokens" versus GPT-5.4 with no regression in response latency. Key improvements: coding, computer use, and multi-step deep research. Handles long multi-step workflows more autonomously with less user input. Available immediately to ChatGPT Plus, Pro, Business, and Enterprise users. API access (GPT-5.5 and GPT-5.5 Pro) opened April 24, 2026. Safety process included ~200 trusted early-access partners and dedicated redteaming for cybersecurity and biology capability risks.

### DeepSeek — V4 Preview

- **DeepSeek-V4-Pro** and **DeepSeek-V4-Flash** — Preview / open-source (released April 24, 2026). Two-variant MoE release, both with 1M-token context windows and a new Hybrid Attention Architecture for improved long-conversation recall.
  - V4-Pro: 1.6T total / 49B active parameters. API pricing: $1.74/million input, $3.48/million output tokens.
  - V4-Flash: 284B total / 13B active parameters. API pricing: $0.14/million input, $0.28/million output tokens.
  - Both licensed MIT. Legacy aliases `deepseek-chat` and `deepseek-reasoner` marked for deprecation on July 24, 2026.
  - V4-Pro tops open-model leaderboards for math and coding; Flash delivers roughly GPT-5.4-level performance at ~1/50th the price.

### Google DeepMind — Gemini Deep Research Agents

- **Deep Research** and **Deep Research Max** — GA (announced April 21–22, 2026). Not a new base model, but a new agent tier built on Gemini 3.1 Pro. Deep Research Max adds access to private data sources (Google Drive, Workspace) alongside public web search. Powered by agentic multi-step reasoning loops with citations.

## Products

### Cursor — Version 3

- **Cursor 3** — GA (April 2026). Major platform update shipping four headline features:
  - **Agents Window**: Dedicated panel for monitoring and directing concurrent background agents.
  - **Cloud-to-local handoff**: Long-running cloud agents can hand off mid-task to a local agent.
  - **Design Mode**: Visual UI iteration loop — describe a UI change, see it rendered, iterate.
  - **Composer 2**: Cursor's own frontier coding model running at 200+ tokens/second.
- Business metrics: 1M+ users, 360K+ paying customers as of April 2026.

### Windsurf (Cognition AI) — SWE-1.5 + Wave 13

- **SWE-1.5** — Now default model on all tiers (replaced SWE-1). Runs at 950 tokens/second on Cerebras hardware; matches Claude Sonnet accuracy on SWE-Bench (40.08%) while being ~14× faster. Included free on every plan as part of Wave 13.
- **Wave 13** additions (shipped earlier this month, now fully rolled out): free parallel agents across all tiers, Cascade Hooks for workflow automation.
- **Pricing**: $20/month Pro, $200/month Max (quota-based, updated March 2026).

### Claude Code (Anthropic)

- Now defaults to **Claude Sonnet 4.6** for both Free and Pro users. No separate announcement; effective as of this week per product page.

### GitHub Copilot (Microsoft)

- No new release this week; current state: **Copilot Coding Agent** GA, 4.7M paid subscribers, 20M total users, 42% market share, 90% Fortune 100 adoption. Multi-model support (Opus 4.6, GPT-5.4, Gemini 3.1 Pro, Grok Code) on Pro+ ($39/month).

## Key Themes

- **48-hour model sprint**: GPT-5.5 (April 23) and DeepSeek V4 Preview (April 24) dropped back-to-back, resuming the release cadence that briefly paused after the March avalanche.
- **Open-source price pressure intensifying**: DeepSeek V4-Flash at $0.14/M input tokens makes capable MoE inference nearly free; V4-Pro undercuts GPT-5.4 by ~50× on price at comparable performance.
- **Coding tools diverging on model strategy**: Cursor ships its own model (Composer 2); Windsurf runs proprietary SWE-1.5; Claude Code leans into the Anthropic model family. Copilot and Windsurf offer multi-model rosters as a hedge.
- **Agentic research as a product**: Google's Deep Research Max is the clearest signal yet that multi-step autonomous research — not just chat — is a GA product category.
