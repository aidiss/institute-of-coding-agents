# Releases — 2026-05-03

## Models

### Anthropic — Claude

- **Claude Opus 4.7** — GA (April 16, 2026). SWE-bench Verified jumped from 80.8% to 87.6%, the highest of any publicly available model. First use of a new tokenizer. Vision resolution raised from 1,568 px to 2,576 px on the long edge (3.3× pixel count). New `xhigh` effort level between `high` and `max`. Introduces task budgets — runtime token caps for long-running agents. Pricing unchanged at $5/$25 per million input/output tokens. Available on GitHub Copilot Pro+, Business, and Enterprise.

### OpenAI — GPT

- **GPT-5.5** — GA (April 23, ChatGPT; API April 24, 2026). First fully retrained base model since GPT-4.5; natively omnimodal. Leads Terminal-Bench 2.0 at 82.7%. Long-context reasoning improves dramatically: MRCR v2 at 1M tokens goes from 36.6% (GPT-5.4) to 74.0%. Available to Plus ($20/mo), Pro ($200/mo), Business, and Enterprise. GPT-5.5 Pro restricted to Pro/Business/Enterprise. API pricing: $5/$30 per million input/output tokens (up from $2.50/$15; ~20% effective cost increase after token efficiency gains). SWE-bench Verified: not yet published for this release.

### Google DeepMind — Gemini / Gemma

- **Gemini 3.1 Ultra** — GA. Largest context window in the Gemini 3.1 lineup (exact token count not confirmed in launch notes). Natively multimodal (text, image, audio, video).
- **Gemini 3.1 Flash-Lite** — GA. 2.5× faster responses and 45% faster output generation versus Flash. Priced at $0.25 per million input tokens.
- **Gemma 4** — GA, Apache 2.0. Open-weight model family; 31B variant benchmarks among top open models globally. Free for commercial use.

### Mistral AI

- **Mistral Medium 3.5** — Public preview (April 29, 2026). 128B dense model, 256k context window. Unified for instruction-following, reasoning, and code with a per-request reasoning-effort toggle. SWE-bench Verified: 77.6%. Self-hostable on four GPUs. Released as open weights under a modified MIT license. API pricing: $1.50 per million input tokens. Pricing drew public criticism on launch day.

### Zhipu AI

- **GLM-4.7** — GA (April 2026). Trained entirely on Huawei Ascend silicon rather than NVIDIA hardware. Claims 1.2% hallucination rate on internal benchmarks. MIT license.

### xAI — Grok

- **Grok Imagine 1.0** — GA. Video generation platform; first video-generation product from xAI.

## Products

### Claude Code (Anthropic)

- **xhigh effort level** — New tier exposed in Claude Code alongside the Opus 4.7 launch; available to Max subscribers. Bridges the gap between high and max compute budgets for autonomous coding sessions.
- **Task budgets** — Agents can now be capped at a token budget to prevent runaway cost on long jobs. Configurable per-session.

### Cursor (Anysphere)

- **Cursor 3** — GA (April 2, 2026). Introduces the Agents Window: run multiple AI agents in parallel across local machines, git worktrees, SSH remotes, and cloud environments simultaneously. Represents a shift from the assistant/chat model to full agent execution as the primary interface.

### GitHub Copilot (Microsoft / GitHub)

- **CLI v1.0.40** — Released May 1, 2026. Fixes PR branch decoration display when model names are long. Adds `/clear` and `/new` slash commands for resetting active custom agent selection mid-session.

### Mistral — Vibe and Le Chat

- **Mistral Vibe remote agents** — Launched with Medium 3.5 (April 29). Asynchronous cloud-based coding sessions launchable from the Vibe CLI or Le Chat. Agents run in the background and return results on completion.
- **Le Chat Work Mode** — Preview. Multi-step task execution with cross-tool actions (research, document generation, external service calls). Powered by Medium 3.5.

### Microsoft — Agent 365

- **Microsoft Agent 365** — GA (May 1, 2026). Dedicated enterprise control plane for managing, monitoring, and auditing AI agents across the Microsoft 365 ecosystem. Priced at $15 per user per month.

### Apple — Xcode

- **Xcode 26.3** — Released ~April 2026. Native integration of both Claude Agent (Anthropic) and OpenAI Codex for agentic iOS and macOS development. First major IDE vendor to ship native agent integration from two competing providers in a single release.

## Open Source

### Aider

- Active weekly point releases through April 2026. Recent additions include GPT-5.5 and Grok 3 model support, improved diff handling, and new `--commit-language` flag. No single landmark version this period; development pace remains high.

### Gemma 4

- Google's Gemma 4 open-weight release (Apache 2.0) is the most notable open-source model drop this period. The 31B variant is directly competitive with mid-tier commercial APIs and is the first Gemma generation to challenge frontier open-weight models (Llama 4, DeepSeek V4) on general benchmarks.

## Key Themes

- **Ten-day frontier sprint**: Claude Opus 4.7 (April 16), GPT-5.5 (April 23), and Mistral Medium 3.5 (April 29) landed within a thirteen-day window. Each is the best model its vendor has ever shipped.
- **SWE-bench compression**: Top-3 commercial SWE-bench Verified scores are now 87.6% (Opus 4.7), 82.7% Terminal-Bench (GPT-5.5), and 77.6% (Mistral Medium 3.5). The gap between first and third has narrowed sharply.
- **Agentic execution as default**: Cursor 3, Mistral Vibe, and Microsoft Agent 365 all ship agent parallelism or async execution as their headline feature. The industry has moved past "AI assistant" framing.
- **Hardware diversification**: GLM-4.7 (Huawei Ascend) signals that frontier training is no longer exclusively NVIDIA-dependent.
- **Open weight stays competitive**: Gemma 4 (Apache 2.0) and Mistral Medium 3.5 (modified MIT) ensure open-weight options track within one generation of closed frontier models.
