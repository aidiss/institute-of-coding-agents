# Releases — 2026-04-24

## Models

### Anthropic — Claude Sonnet 5

- **Claude Sonnet 5** (`claude-sonnet-5-20260401`) — GA (released April 1, 2026). The headline release of the month: 92.4% on SWE-bench Verified (up from Opus 4.6's 80.8%), 88.3% on OSWorld-Verified (above the 72.4% human expert baseline), and 96.2% on GPQA Diamond. Ships at the same $3 / $15 per million token pricing as Sonnet 4.6 and is now the default model on claude.ai.
- Introduces a **1-million-token context window** — a 4× increase over Sonnet 4.6.
- **"Dev Team" mode** — automatically spawns specialized sub-agents that collaborate in parallel on complex engineering tasks; available on Pro/Max/Team/Enterprise tiers.
- Available via Anthropic API, Amazon Bedrock, and Google Vertex AI from day one.

### Anthropic — Claude Opus 4.7

- **Claude Opus 4.7** — GA (released April 16, 2026). Anthropic's reasoning-and-agent flagship. SWE-bench Verified jumped from 80.8% (Opus 4.6) to 87.6%. First Claude model with high-resolution image input (max 2576 px / 3.75 MP). Pricing unchanged: $5 / $25 per million tokens.
- New **task budget API** — pass a token estimate for a full agentic loop; the model uses a running countdown to prioritize work and exit gracefully when the budget is consumed.
- New **`xhigh` effort level** — sits between `high` and `max` on the effort parameter; Claude Code defaults to `xhigh` for many coding workflows after 4.7.
- As of **April 23, 2026**, Opus 4.7 is the default model for **Claude Code** Auto mode (Max subscribers).

### Meta — Muse Spark

- **Muse Spark** — Released April 8, 2026 by **Meta Superintelligence Labs** (led by Alexandr Wang). The first model in Meta's new Muse series, built from a ground-up rewrite of Meta's pretraining stack. **Closed source; not publicly downloadable.**
- Natively multimodal: accepts text, image, and voice input (text-only output at launch). Key capabilities: visual chain-of-thought, parallel agent orchestration ("Contemplating" mode), and tool use across Meta's app surfaces.
- Currently powers the Meta AI app and website; rolling out to WhatsApp, Instagram, Facebook, and AI glasses. **Private API preview** for select partners; no public API as of April 24.
- Meta reports reaching equivalent capability to Llama 4 Maverick with more than an order of magnitude less compute, attributable to architecture and data-curation improvements.

### OpenAI — GPT-5.5 "Spud" (not yet released)

- Pretraining completed approximately March 24, 2026. As of April 24, **not shipped**. Expected capabilities: 256K–512K context, improved multi-step tool use. No release date or pricing announced.

## Products

### Cursor 3.0

- **Cursor 3.0** — Released April 2, 2026. Major overhaul enabling **parallel agents across repos and environments** — locally, in Git worktrees, in the cloud, and over remote SSH. Agents Window provides a unified multi-pane view of concurrent sessions.
- **Bugbot improvements** (April 8) — self-improvement in real time, MCP support, Bugbot Autofix; resolution rate now **78%**.
- **CLI `/debug` mode** (April 14) — generates hypotheses, inserts log statements, and uses runtime output to pinpoint root causes.
- **Interactive Canvases** (April 15) — AI-generated dashboards and custom interfaces (tables, diagrams, charts) rendered in the side panel alongside terminal, browser, and source control.
- **Self-hosted cloud agents** — new option to run Cursor's cloud agent infrastructure entirely in-network, keeping code and secrets on internal machines.

### Claude Code

- **Opus 4.7 as default** (April 23, 2026) — Auto mode for Max subscribers now routes to Opus 4.7.
- **`/effort xhigh`** — new effort tier for Opus 4.7.
- **`/ultrareview`** — multi-agent code review slash command; Max subscribers receive a small number of free runs with paid add-on beyond that.
- Reduced permission prompts and improved Windows support shipped alongside the model update.

### GitHub Copilot

- **VS Code: Autopilot** — fully autonomous agent sessions in **public preview** (shipped March, announced April 8). Also added integrated browser debugging, image and video support in chat, and a unified editor for managing chat customizations.
- **Plan split** — the singular Copilot Individual plan divided into an essential tier and a professional tier. Opus 4.7 available on **Pro+** only; removed from base Pro.
- **Copilot CLI v1.0.34** (April 20, 2026) — improved rate-limit error messaging (now says "session rate limit"); v1.0.33 added `--resume` / `--continue` flags that automatically inherit `--remote` for session resumption.
- **Data training policy change** (effective April 24, 2026) — GitHub may use interactions from Copilot Free, Pro, and Pro+ subscribers to train models unless users have opted out.

### Windsurf

- **Wave 13 (active through April)** — SWE-1.5 as default model (described as 13× faster than Sonnet 4.5); Arena Mode for blind in-IDE model comparisons; Plan Mode for task planning before code generation; Parallel Multi-Agent Sessions via Git Worktrees; versions v2.0.44 (April 15) → v2.0.61 (April 17) shipped this week.
- **Acquisition context** — Google acqui-hired founding team ($2.4 B); Cognition AI acquired remaining Windsurf business ($250 M). Product continues operating; existing user continuity confirmed.
- **Pricing** (March 19, 2026) — quota-based model: Pro at $20/month; new Max tier at $200/month.

## Open Source

### OpenHands

- **v1.6.0** — Released March 30, 2026 (most recent release as of April 24). Built on the `software-agent-sdk` (v1.x architecture introduced in v1.0.0, December 2025). Key architectural principles: optional isolation, stateless design, strict separation of concerns, two-layer composability.
- New integrations: **Slack, Jira, and Linear** — agents respond to Slack messages, create Jira tickets, and update Linear issues natively.
- 68K+ GitHub stars; MIT-licensed; available at openhands.dev and via Docker self-host.
- SDK is the reference implementation for the MLSys 2026 paper *"The OpenHands Software Agent SDK: A Composable and Extensible Foundation for Production Agents"*.

### Aider

- Active maintenance; no major version in this window. Added support for Claude 4.x and Gemini 3 Preview models; tree-sitter tags for Fortran, Haskell, Julia, and Zig; removed deprecated `google-generativeai` dependency.
- 41K+ GitHub stars; Apache 2.0.

## Key Themes

- **Sonnet 5 is the value inflection point**: At $3/$15 per million tokens, Sonnet 5's SWE-bench score (92.4%) beats what Opus 4.6 could do at 2.5× the price. The cost-per-solved-ticket curve bent sharply downward in April.
- **Meta repositioning around closed models**: Muse Spark is the first model in years from Meta that is not open-weight — a deliberate strategic shift under Meta Superintelligence Labs. The Llama family continues, but Meta's frontier compute is now going into a proprietary stack.
- **Parallel agents becoming table stakes**: Cursor 3.0, Windsurf Wave 13, and Claude Code's Dev Team mode all ship some form of concurrent multi-agent execution in the same window. "One agent per task" is the old model.
- **Copilot's capacity crunch**: New-subscriber pauses and plan restructuring signal that GitHub is managing demand-side pressure — remarkable for a product backed by Microsoft's hyperscaler infrastructure.
- **OpenHands reaching production maturity**: v1.6.x with Slack/Jira/Linear integrations and a published SDK puts it firmly in competition with commercial products (Devin, Augment) rather than research tools.
