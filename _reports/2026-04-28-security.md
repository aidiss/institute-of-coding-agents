# Security Brief — 2026-04-28

Track of vulnerabilities, supply chain attacks, and safety incidents affecting AI coding agents.

---

## Incidents & Vulnerabilities

### CVE-2025-53773 — GitHub Copilot Prompt Injection → RCE (CVSS 9.6)
**Status: Disclosed / Patched**

A hidden prompt injection embedded in pull request descriptions can trigger remote code execution through GitHub Copilot. CVSS score of 9.6 makes this one of the highest-severity disclosures in AI coding tooling to date. Microsoft has issued a patch; users should update Copilot extensions immediately.

### CVE-2026-21516 — GitHub Copilot "Reprompt Attack" Data Theft
**Status: Disclosed**

A reprompt attack against Microsoft Copilot allows an attacker-controlled document to redirect Copilot into silently exfiltrating sensitive data from the developer's environment. Detailed in a proof-of-concept published by security researchers and covered by The Hacker News.

### "Comment and Control" — Claude Code Security Review Action
**Status: Disclosed / No patch confirmed**

Researchers demonstrated that Anthropic's Claude Code Security Review GitHub Action is exploitable via prompt injection in PR comments. Notably, Anthropic's own system card for the feature acknowledges it is "not hardened against prompt injection." A single crafted comment caused three separate AI coding agents tested to leak secrets.

### EchoLeak — Microsoft 365 Copilot Zero-Click Exfiltration
**Status: Disclosed / Patched**

A zero-click prompt injection vulnerability in Microsoft 365 Copilot allows silent exfiltration of enterprise data without any user interaction. Microsoft has shipped a fix; organisations on older enterprise update rings should verify the patch has been applied.

### Google Antigravity — Prompt Injection → Sandbox Escape
**Status: Disclosed / Patched**

Researchers produced a proof-of-concept prompt injection against Google's AI-based Antigravity tool that achieves sandbox escape and arbitrary code execution. Google has patched the critical RCE flaw.

## Supply Chain

### MCP SDK Design Flaw — RCE Across the AI Ecosystem
**Status: Disclosed (≈ 2026-04-16) / No upstream architectural fix**
**CVEs: CVE-2025-49596, CVE-2026-22252, CVE-2026-22688, CVE-2025-54994, CVE-2025-54136, CVE-2026-23744**

A systemic "by-design" weakness in Anthropic's Model Context Protocol SDK enables direct configuration-to-command execution via the STDIO interface. Any implementation that spins up an STDIO server executes the supplied OS command before returning an error, giving an attacker arbitrary code execution.

- **Affected SDKs:** Python, TypeScript, Java, Rust (all official MCP SDK languages)
- **Estimated blast radius:** 7,000+ publicly accessible servers; packages totalling 150 M+ downloads
- **Per-project CVEs (all share the same root cause):**
  - CVE-2025-49596 — MCP Inspector
  - CVE-2026-22252 — LibreChat
  - CVE-2026-22688 — WeKnora
  - CVE-2025-54994 — @akoskm/create-mcp-server-stdio
  - CVE-2025-54136 — Cursor
  - CVE-2026-23744 — MCPJam Inspector (listens on `0.0.0.0` with no authentication; crafted HTTP installs a server and achieves RCE with no user interaction)

Individual projects have shipped point fixes; the underlying protocol design remains unresolved.

### MCP Sampling Attack Vectors (Unit 42 / Palo Alto)
**Status: Research / No CVE assigned**

Palo Alto Unit 42 published an analysis of prompt injection attack chains that exploit the MCP sampling feature, where MCP servers request LLM completions through the client. An attacker-controlled server can embed adversarial instructions that propagate through the sampling chain to gain elevated access.

### Slopsquatting — AI-Hallucinated Package Names as a Supply Chain Vector
**Status: Ongoing / No patch possible at ecosystem level**

LLMs consistently hallucinate package names that do not exist. When attackers register those names on PyPI or npm before the hallucination is noticed, any developer (or coding agent) following the AI's advice installs malicious code. Key data points:

- ~20% of AI-generated Python and JavaScript code samples recommend non-existent packages.
- 58% of hallucinated package names are repeated across multiple model runs, meaning squatters can predict targets reliably.
- A researcher registered the hallucinated package `huggingface-cli` on PyPI; it accumulated 30,000+ downloads within three months.

2026 research highlights that autonomous coding agents (Cursor, Claude Code, GitHub Copilot Workspace) compound the risk: unlike advisory tools, they select and install dependencies autonomously, potentially before any human reviewer sees the choice.

### 92% of AI-Generated Code Contains Critical Vulnerabilities
**Status: Research finding (Sherlock Forensics 2026 report)**

A 2026 security audit found that 92% of code produced by AI coding tools contained at least one critical vulnerability. The report covers output from the major agent platforms and categorises findings across OWASP Top 10 categories.

## Research & Advisories

### Adaptive Attacks Beat SOTA Defences >85% of the Time
A comprehensive review published in *Information* (MDPI, 2026) documents that attack success rates against state-of-the-art prompt injection defences exceed 85% when adaptive strategies are employed. The root cause identified: LLMs have no reliable mechanism to distinguish instructions from data, and all ingested content is treated as equally trustworthy.

Reference: *Prompt Injection Attacks in Large Language Models and AI Agent Systems* — [https://www.mdpi.com/2078-2489/17/1/54](https://www.mdpi.com/2078-2489/17/1/54)

### Systematic Analysis of Prompt Injection in Coding Assistants (arXiv 2601.17548)
An arXiv pre-print provides a structured taxonomy of prompt injection attack surfaces specific to AI coding assistants: Skills, Tools, and Protocol Ecosystems (including MCP and LSP). Recommended mitigations include sandboxed tool execution, explicit trust boundaries in protocols, and user-confirmation gates for all side-effecting actions.

### OX Security — MCP Supply Chain Advisory
OX Security released a dedicated advisory cataloguing RCE vulnerabilities across the MCP ecosystem and recommending organisations audit all installed MCP servers against the published CVE list.

### Cycode — Top AI Security Vulnerabilities 2026
Cycode's annual roundup calls out prompt injection, data exfiltration via agentic workflows, and insecure MCP/plugin integrations as the three highest-priority concerns for AppSec teams this year.
