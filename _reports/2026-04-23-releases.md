# Releases — 2026-04-23

## Models

### Anthropic — Claude Opus 4.7

- **Claude Opus 4.7** — GA (released April 16, 2026). Described as Anthropic's most capable generally available model to date, with meaningful gains in long-horizon agentic execution, knowledge work, and vision tasks. First Claude model with high-resolution image support (max 2576 px / 3.75 MP). Pricing unchanged from Opus 4.6. Available via Anthropic API, Amazon Bedrock (GA April 20), and Google Vertex AI.
- As of **April 23, 2026**, Opus 4.7 becomes the default model for **Claude Code** (replaces Sonnet 4.6 in Auto mode for Max subscribers).

### Meta — Llama 4 Scout & Maverick

- **Llama 4 Scout** — GA (released April 5, 2026). 17B active parameters, 16 experts, MoE architecture. Industry-leading **10M-token context window**. Fits in a single NVIDIA H100. Open-weight download on Hugging Face and llama.com.
- **Llama 4 Maverick** — GA (released April 5, 2026). 17B active parameters, 128 experts. Beats GPT-4o and Gemini 2.0 Flash on major multimodal benchmarks per Meta's reporting. Both models process text, image, and video natively — first open-weight natively multimodal MoE models in the Llama family.

### Alibaba — Qwen3.6-Plus & Qwen3.6-35B-A3B

- **Qwen3.6-Plus** — Proprietary, API access via Qwen Studio and Alibaba Cloud (released April 2, 2026). Agentic coding and multimodal reasoning focus; tops several coding and agent benchmarks at release.
- **Qwen3.6-35B-A3B** — Open source under **Apache 2.0** (released April 16, 2026). Sparse MoE, 35B total / 3B activated parameters. Available on Hugging Face and GitHub.

### OpenAI — "Spud" (forthcoming)

- Internally codenamed **Spud** (likely GPT-5.5 or GPT-6), pretraining completed approximately March 24, 2026. Expected release window mid-April to early May; as of April 23 it has not shipped. Anticipated: extended context (256K–512K), improved multi-step tool-use. **Not yet released — no pricing or availability announced.**

## Products

### Claude Code

- **Opus 4.7 as default** (April 23, 2026) — Auto mode for Max subscribers now routes to Opus 4.7.
- **`/effort xhigh`** — New effort tier for Opus 4.7, sitting between `high` and `max` for controlling compute spend.
- **`/ultrareview`** — New slash command for deep multi-agent code review. Max subscribers receive a small number of free runs; additional runs are a premium add-on.
- **Reduced permission prompts** and improved **Windows support** shipped alongside the model update.
- **Terminal-matching theme** added to the IDE extension.

### GitHub Copilot

- **Claude Opus 4.7 rolling out** on Copilot (April 2026); available in **Pro+** plans. Opus removed from base Pro plans.
- **Plan changes (April 20, 2026)** — New sign-ups for Copilot Pro, Pro+, and Student plans **paused** to protect service quality for existing subscribers.
- **Copilot CLI v1.0.34** (April 20, 2026) — Improved rate-limit error messaging (now says "session rate limit"); v1.0.32 added `--resume` with short session ID prefixes, usage-limit warnings, and file-attachment support.
- **VS Code: Autopilot** — Fully autonomous agent sessions in **public preview**; also added integrated browser debugging and image/video support in chat.

### Windsurf (Cognition / Google)

- **Acquisition closed** — Google acqui-hired Windsurf's founding team for **$2.4 billion**; Cognition AI separately acquired the remaining Windsurf business for **$250 million**. Operational continuity of the Windsurf product is confirmed for existing users.
- **Pricing change (March 19, 2026)** — Credit-based pricing replaced with quota-based model: Pro raised from $15 to **$20/month**; new **Max tier at $200/month**.
- **Wave 13 features (Dec 2025, in active deployment through April)** — SWE-1.5 as default model; true parallel agents via Git Worktrees with multi-pane/tab Cascade; Arena Mode for blind model comparison; Plan Mode; dedicated agent terminal; context window indicator; Cascade Hooks.

## Open Source

### OpenHands

- **$18.8M funding raised** (announced April 2026) to build cloud coding agents. Platform reports **77.6% success rate on SWE-Bench Verified** (Claude 3.5 Sonnet Thinking, own harness) and 87% same-day resolution on enterprise bug tickets in production.
- New integrations: **Slack, Jira, and Linear** — agents can respond to Slack messages, create Jira tickets, and update Linear issues natively.
- MIT-licensed core; available at openhands.dev (cloud) and self-hosted via Docker.

### Aider

- Active maintenance continues; no major version release in this window. Added support for Claude 4.x and Gemini 3 Preview models; tree-sitter tags for Fortran, Haskell, Julia, and Zig; removed deprecated `google-generativeai` dependency.
- 40K+ GitHub stars, 4.1M+ installs. Apache 2.0; self-hosted.

### Qwen3.6-35B-A3B

- Alibaba open-sourced this sparse MoE model on **April 16, 2026** under Apache 2.0. Focused on programming capability improvements. Available on GitHub (`QwenLM/Qwen3.6`) and Hugging Face.

## Key Themes

- **Agentic defaults solidifying**: Claude Code's shift to Opus 4.7 as the default signals that frontier-tier models are now the baseline expectation for coding agents, not a premium option.
- **Open-weight MoE proliferating**: Llama 4 Scout/Maverick and Qwen3.6-35B-A3B both use sparse MoE, achieving frontier-competitive performance at reduced inference cost. The 10M-token context of Scout is a new ceiling for open-weight models.
- **IDE consolidation accelerating**: Windsurf's dual acquisition (Google founders + Cognition remainder) concentrates the IDE market. Three of the dominant coding IDEs (Windsurf → Google/Cognition, Cursor independent, Claude Code → Anthropic) now have major backer lock-in.
- **Copilot gating access**: GitHub pausing new Copilot sign-ups is a rare capacity-constraint signal from a hyperscaler-backed product — suggests demand-side pressure is real.
- **OpenHands establishing enterprise surface**: Slack/Jira/Linear integrations move it from a developer toy to a workflow-embedded agent, competing directly with Devin and Augment.
