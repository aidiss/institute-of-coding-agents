# Releases — 2026-04-27

## Models

### Moonshot AI — Kimi K2.6

- **Kimi K2.6** — GA (April 21, 2026; preview April 13). 1T-parameter MoE, 32B active parameters, 262.1k-token context window, vision, and native agentic capabilities. Defining capability is long-horizon execution — autonomous progress across thousands of steps without user redirection. Agent swarm scaling reaches 300 concurrent sub-agents and 4,000 coordinated steps. Weights published on Hugging Face under Modified MIT license; available via Kimi.com, Kimi App, official API, and Kimi Code CLI.
- **Benchmark highlights**: SWE-Bench Verified 80.2, BrowseComp 83.2, Terminal-Bench 2.0 66.7, HLE-Full (with tools) 54.0 — topping GPT-5.4 (52.1), Claude Opus 4.6 (53.0), and Gemini 3.1 Pro (51.4) on the last metric.
- Also available on Cloudflare Workers AI as of April 20.

### xAI — Grok 4.3 Beta + Speech APIs

- **Grok 4.3 Beta** — Limited preview (April 17, 2026). Exclusive to SuperGrok Heavy subscribers ($300/month). Carries over the 16-agent Heavy system and 2M-token context window from Grok 4.20. Key additions:
  - Native video understanding in chat.
  - Direct document generation: downloadable PDFs, spreadsheets, and PowerPoint decks from conversation.
  - Improved multi-step reasoning on complex creative and strategic tasks.
  - No cross-session memory — a notable gap at this price point.
- **xAI Speech-to-Text API** — GA (April 2026). Transcription in 25 languages, batch and streaming modes, multi-speaker diarization.
- **xAI Text-to-Speech API** — GA (April 2026). Priced at $4.20 per million characters.

### Google DeepMind — Gemini 3.1 Flash-Lite Preview

- **Gemini 3.1 Flash-Lite** — Preview (April 2026). Budget-tier variant in the Gemini 3.1 family. Reports 2.5× faster response times and 45% faster output generation than its predecessor. Targets cost-sensitive developer workloads and real-time streaming use cases. Pricing not yet finalized at preview.

### Anthropic — Claude Opus 4.7 (reference)

- **Claude Opus 4.7** — GA (April 16, 2026). 13% coding benchmark improvement over Opus 4.6, 3× more production tasks resolved. First Claude model with high-resolution image input (up to 2576px / 3.75MP). Introduces task budgets and a new `xhigh` effort level. 1M-token context, 128k max output. Pricing: $5/M input, $25/M output (unchanged from Opus 4.6).

## Products

### GitHub Copilot — Pricing Restructure + Autopilot Preview

- **Copilot plan restructuring** — April 20, 2026. GitHub published a major overhaul of individual developer plans. Details of new tier boundaries not fully disclosed yet; change targets solo developers previously on legacy Copilot Individual.
- **Copilot Autopilot** — Public preview (rolled out earlier this month, now broadly available). Fully autonomous agent sessions: approves its own actions, retries on errors, and continues until task completion without manual intervention. Agent permissions let users select autonomy level per session.
- **VS Code extension updates**: v1.0.36 (April 24) — selection indicator in subcommand picker; v1.0.35 (April 23) — tab-completion for slash command arguments; v1.0.34 (April 20) — improved rate-limit error messaging.

## Key Themes

- **Open-weight agentic coding now at frontier**: Kimi K2.6 at 80.2 SWE-Bench Verified makes it competitive with leading closed models on agentic tasks, continuing DeepSeek V4's pattern of open-weight models closing the gap within days of a closed-model wave.
- **xAI broadening beyond text**: Grok 4.3's video input and document output, alongside the GA of Speech and TTS APIs, signals xAI moving toward a multimodal platform rather than a pure LLM.
- **Budget tier sharpening**: Gemini 3.1 Flash-Lite and DeepSeek V4-Flash both target the sub-$0.30/M output price band; competition here is now as intense as at the frontier.
- **GitHub Copilot repricing**: The April 20 plan restructuring is the first significant individual-tier change since Copilot launched; details will matter for the 4.7M paid subscriber base.
