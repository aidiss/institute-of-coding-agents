# Releases — 2026-04-20

## Models

### Claude Opus 4.7 (Anthropic) — GA, April 16, 2026
Anthropic released Claude Opus 4.7 on April 16. Key upgrades over 4.6: stronger multi-step software engineering on hard tasks, vision resolution up to 2,576px on the long edge (3× prior limit), and a new automated cybersecurity safeguard layer that blocks prohibited requests. Pricing unchanged from Opus 4.6: **$5/M input, $25/M output tokens**. Available via Anthropic API, Amazon Bedrock, Google Vertex AI, and Microsoft Foundry. Security professionals needing access for legitimate work can apply through Anthropic's new Cyber Verification Program.

### Claude Sonnet 4.6 (Anthropic) — GA (recent)
Now leading the GDPval-AA Elo benchmark at 1,633 points — near-Opus performance at Sonnet pricing. A Claude Haiku 4.5 variant is expected before end of April.

### Gemma 4 (Google DeepMind) — GA, April 2, 2026
Four open-weight variants released under Apache 2.0: **E2B, E4B, 26B MoE, and 31B Dense**. Built from the same research base as Gemini 3. Highlights: up to 256K context, native vision and audio, 140+ languages. The 31B Dense ranks #3 and the 26B MoE ranks #6 on the Arena AI text leaderboard. The 26B MoE activates only 3.8B parameters at inference for low-latency use. Weights available on Hugging Face, Kaggle, and Ollama.

### Gemini 3.1 Pro (Google) — recent
Topped GPQA Diamond reasoning benchmark at 94.3%.

### GPT-5.4 (OpenAI) — GA, March 5, 2026
Released just before this window but still recent. Record scores on OSWorld-Verified and WebArena Verified computer-use benchmarks. GPT-5.5 ("Spud") has completed pretraining; no public launch date yet.

### Meta Llama 4 Maverick — GA (recent)
400B parameters, 10M token context window — currently the top open-weight option by capability. Llama 4 Scout holds the largest context window at 10M tokens in a smaller footprint.

## Products

### GitHub Copilot
- **Claude Opus 4.7** rolling out in Copilot as of April 2026 — 7.5× premium request multiplier, promotional pricing through April 30.
- **Copilot CLI v1.0.32** (April 17): short session ID prefixes for `--resume` / `/resume`.
- **Copilot CLI v1.0.31** (April 16): fixed prompt frame rendering on Windows and Ubuntu terminals.
- **`gh skill` command** (public preview): discover, install, manage, update, and publish agent skills with version pinning, provenance tracking, and supply chain safeguards via GitHub CLI.
- **Data residency** for US and EU regions — all inference processing stays within the designated geography.
- **VS Code**: users can now attach screenshots and videos to chat messages; agents can return images or recordings of changes in a reviewable carousel with zoom, pan, and thumbnails.
- **VS Code March releases** changelog published April 8.

### Windsurf (Cognition AI) — Wave 13, March 2026
Parallel Multi-Agent Sessions, Arena Mode (blind model quality testing), Plan Mode (separate planning from code generation), and in-IDE local preview shipped in Wave 13. Pricing moved from credit-based to quota-based on March 19: Pro at **$20/month**, new Max tier at **$200/month**. (Windsurf was acquired by Cognition AI — makers of Devin — for $250M in December 2025.)

### Cursor (Anysphere)
No specific product release this week, but the company hit **$2B ARR** in March 2026 and is now valued at up to **$60B**. Holds ~18% developer workplace adoption (tied with Claude Code per JetBrains January 2026 survey).

## Open Source

### OpenHands 1.0.0
Major version release. Rebuilt on the new `software-agent-sdk` with significant performance optimizations. New UI features: a Task List tab in the right panel with real-time agent status, and a slash command menu surfacing available agent skills. Added model support for Claude Opus 4.6, Claude Sonnet 4.6, Gemini 3.1 Pro Preview, GLM-4.7, GLM-5, Kimi-K2.5, and Qwen3-Coder-Next. Reported 77.6% SWEBench score. 65K+ GitHub stars.

### Aider (recent updates)
Added support for Gemini 2.5 Pro, Gemini 2.5 Flash (with thinking tokens), and the Claude Sonnet 4 / Opus 4 model series. New flags: `--add-gitignore-files` (edit files normally excluded by .gitignore), `--attribute-co-authored-by` (co-author trailer in commit messages), `--shell-completions` (generate bash/zsh completions). Playwright is now used for `aider scrape` when available. Windows linter fix via `oslex`. Currently 40K+ GitHub stars, 4.1M installs.
