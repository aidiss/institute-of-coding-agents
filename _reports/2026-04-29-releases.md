# Releases — 2026-04-29

## Models

### DeepSeek — V4 Preview

- **DeepSeek V4 Preview** — Open preview (April 24, 2026). Two variants: **V4-Pro** (1.6T total / 49B active params) and **V4-Flash** (284B total / 13B active params). Open-source weights on Hugging Face. Supports 1M-token context and dual Thinking / Non-Thinking modes. API available immediately; compatible with both OpenAI and Anthropic ChatCompletions API formats. Benchmark claim: beats all current open models on Math/STEM/Coding, rivals top closed-source models. Confirmed to run on Huawei Ascend AI clusters. Released 24 hours after GPT-5.5 (April 23).

## Products

### Anthropic — Claude Code Postmortem

- **Claude Code quality degradation postmortem** — Published (April 23, 2026). Anthropic publicly documented ~6 weeks of reported quality regression in Claude Code, tracing it to three overlapping changes: (1) reasoning effort downgraded from "high" to "medium" on March 4 (reversed April 7); (2) a bug introduced March 26 that cleared thinking history every turn instead of once after idle (fixed April 10); (3) a system-prompt verbosity reduction added April 16 that hurt coding quality (reverted April 20). All issues resolved by v2.1.116 as of April 20. As compensation, Anthropic reset usage limits for all subscribers as of April 23.

### Anthropic — Claude Code Access Change

- **Claude Code removed from $20/month Pro tier** — Effective April 21, 2026 (for new subscribers). Claude Code access is no longer included in the base Pro subscription. Signals repositioning of Claude Code as a premium/enterprise product.

### Anthropic — Claude Opus 4.7 as Claude Code Default

- **Claude Opus 4.7 becomes default model for Claude Code** — Changed April 23, 2026. Achieves 87.6% on SWE-bench Verified and 64.3% on SWE-bench Pro. Previously released GA on April 16.

### OpenAI — Agents SDK "Next Evolution"

- **OpenAI Agents SDK major update** — GA (April 15, 2026, rolling into late April). New capabilities: configurable memory, sandbox-aware orchestration, Codex-style filesystem tools, subagent support, and provider-agnostic support for 100+ LLMs. Python-first; TypeScript support planned. Standard API pricing with no additional cost beyond token usage.

## Open Source

### Claw Code

- **Claw Code** — Launched April 2, 2026; went viral through late April. Origin: on March 31, 2026, Anthropic's Claude Code source map (59.8 MB, ~512K lines of TypeScript) was accidentally published to npm. The community used it as a reference to build a clean-room reimplementation in Rust + Python. MIT-licensed. Surpassed 72,000 GitHub stars within days of launch; described as one of the fastest repos to reach 100K stars. Positioned as an open, inspectable alternative to proprietary agent harnesses. GitHub: [ultraworkers/claw-code](https://github.com/ultraworkers/claw-code).

### Shopify AI Toolkit

- **Shopify AI Toolkit** — GA (April 10, 2026). MIT license. MCP plugins for Claude Code, Cursor, and Gemini CLI giving AI coding assistants direct access to Shopify APIs. One of the first major platform companies shipping MCP integrations as official developer tools.

### Archon

- **Archon** — Released (April 11, 2026). YAML-defined workflow engine for deterministic AI coding pipelines. Targets teams needing reproducible, auditable agent workflows without writing orchestration code.
