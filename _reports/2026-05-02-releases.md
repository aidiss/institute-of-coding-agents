# Releases — 2026-05-02

## Models

No new frontier model releases confirmed on May 2. The major wave of April model launches (GPT-5.5 on April 23–24, Claude Opus 4.7 on April 16, DeepSeek V4 on April 24) is being absorbed into tooling integrations this week rather than new model drops.

---

## Products

### Microsoft — Agent 365

- **Microsoft Agent 365** — GA (May 1, 2026). A dedicated governance and security control plane for enterprise AI agents, separate from Microsoft 365 Copilot. Manages agents built on Microsoft AI Foundry, Copilot Studio, and third-party agent platforms. Pricing: $15 per user per month. Positioned as an enterprise agent management layer covering policy enforcement, audit logging, and agent lifecycle governance.

### GitHub — Copilot CLI v1.0.40

- **GitHub Copilot CLI v1.0.40** — GA (May 1, 2026). Terminal-first coding agent bringing agentic capabilities (build, debug, deploy) to the shell without leaving the terminal. New in this release: smoother streamed text output, client credentials OAuth support, and cloud agent session startup over 20% faster via optimized GitHub Actions custom runner images.

### GitHub — Copilot in Visual Studio (April Update)

- **Copilot in Visual Studio — April 2026 update** — GA (April 30, 2026). Key additions: cloud agent sessions launchable directly from the IDE; custom agents gain user-level (not just org-level) support; new Debugger agent validates suggested fixes against live runtime behavior; auto-detect-and-format button in the text visualizer uses Copilot to identify encoding/compression formats and decode strings.

### Windsurf — Devin Terminal Integration

- **Devin as terminal agent in Windsurf** — GA for all Windsurf subscribers (April 28, 2026). Devin is now available as a CLI agent within Windsurf, running on the user's local machine with full codebase and toolchain access. Handoff to Devin Cloud sessions supported. Available at no extra cost within existing Windsurf subscriptions. Version 2.1.32 (April 29) patched a crash on conversation switch and resolved an auth issue for Devin Cloud.

## Key Themes

- **Enterprise agent governance becomes a product category**: Microsoft Agent 365 is the clearest signal yet that managing, auditing, and governing AI agents is separating out as a distinct product surface — distinct from the coding/productivity tools that run those agents.
- **Terminal becomes a first-class AI agent surface**: GitHub Copilot CLI v1.0.40 and Windsurf's Devin terminal integration both shipped within 72 hours of each other, marking the terminal as the next convergence point after IDE extensions.
- **Model integration pace outstrips model releases**: This week the news is integrations (GPT-5.5 and Opus 4.7 landing across Copilot, Windsurf, and Cursor), not new model drops — indicating the April wave is still propagating through tooling.
