# Releases — 2026-05-07

## Models

### OpenAI — GPT-5.5 Instant ("the new ChatGPT default")

- **GPT-5.5 Instant** — GA (released May 5, 2026). Replaces GPT-5.3 Instant as the ChatGPT default for non-reasoning queries. Rolling out first to Plus, Pro, Business, and Enterprise; Free/Go/education tiers "in the coming weeks." API alias `chat-latest`.
- **Headline numbers (OpenAI's own)**: 52.5% fewer hallucinated claims than GPT-5.3 Instant on high-stakes prompts (medical, legal, financial); ~30% shorter responses by line and word count; new memory-source citations across all models so the user can see *which* prior conversation, file, or Gmail thread a fact came from.
- **Pricing**: inherits the GPT-5.5 family rate card — $5/M input, $30/M output, 1M-token context. Batch/Flex at half price; Priority at 2.5×; >272K input tokens billed at 2× input / 1.5× output.
- Strategic read: this is the first time OpenAI has rebased the *non-reasoning* default — the model used by the long tail of ChatGPT traffic — onto the GPT-5.5 series. Most of OpenAI's installed base will move onto GPT-5.5-class quality without anyone touching a model picker.

### Anthropic — Claude Opus 4.7 (default-tier promotion)

- **Opus 4.7 promoted to default** on Max and Team Premium plans (effective May 6, 2026, announced at *Code with Claude SF*). Previously Sonnet 4.6 was default; Opus 4.7 was opt-in for those tiers.
- **New `xhigh` effort level** between `high` and `max`, recommended for coding work; an interactive `/effort` slider lands in Claude Code v2.1.129 (see Products).
- No model retraining or version bump — same Opus 4.7 weights GA'd on April 16. The change is in *defaults*, *limits*, and *effort tiers*, not model capability.

### Quiet at other frontier labs

- No new GA or preview releases from Google (Gemini), Meta, Mistral, DeepSeek, Qwen, Z.AI/GLM, Moonshot, or xAI on May 5–7. The wave that defined late April (Opus 4.7, GPT-5.5, DeepSeek V4 preview, Mistral Medium 3.5, Gemma 4, Grok 4.3) has flowed entirely into integration and tooling work this week.

## Products

### Anthropic — *Code with Claude*, San Francisco (May 6, 2026)

Anthropic's developer conference shipped feature drops, not promises. Highlights actually GA or in beta as of May 6:

- **Claude Code Code Review** — automated PR review surfaced as a first-class Claude Code feature. Anthropic reports every internal team uses it; now exposed to subscribers.
- **Remote Agents** — control a Claude Code session running on your laptop from a mobile device. Same authenticated session, full repo and tool access, asynchronous status updates from the phone client.
- **Doubled Claude Code rate limits** on Pro, Max, Team, and seat-based Enterprise plans. Peak-hour throttling on Pro and Max removed entirely. Tied to a newly announced **SpaceX / Colossus 1 compute partnership** — Anthropic claims ~300 MW of capacity and 220K+ NVIDIA GPUs coming online within a month.
- **Ten new plugins** for Cowork and Claude Code, Microsoft 365 integrations, and a financial-services / insurance vertical MCP app.
- **Claude Agent SDK** — Anthropic explicitly positioned the SDK powering Claude Code, Claude Desktop, and Cowork as the same surface external builders are now invited to use; no longer two parallel codebases.

### Claude Code v2.1.129 (May 6, 2026)

- New **Opus 4.7 `xhigh`** effort level exposed in the model picker.
- **Auto mode** for Max subscribers on Opus 4.7 — Claude Code picks the effort level per turn.
- New `/effort` interactive slider replacing keyword-only effort selection.
- Bug fixes: `/context` ASCII rendering, `/agents` arrow-key navigation, and a quiet but consequential fix where Opus 4.7 sessions had been counting against a 200K context window instead of the native 1M.

### Cursor — Cursor 3.3 (May 6, 2026)

- **Context Usage Breakdown** in the agent UI: per-component view of how much context is being consumed by rules, skills, MCP servers, and subagents, replacing the previous opaque token counter. Useful in long sessions where users couldn't tell whether a stalled agent was burning context on tools or on conversation history.

### Windsurf — 2.2.17 (May 6, 2026)

- **Devin Review and Quick Review** — Devin-powered PR review modes promoted from preview to GA across all Windsurf IDE subscribers at no extra cost.
- **Agent Command Center** updates: agent-inbox list views, a sortable/filterable sessions sidebar, and faster session loading.
- Reliability: Windows updater bug fix, MCP server stability fixes, Devin Local agent reliability improvements.

### Cognition — Devin (May 6, 2026 release notes)

- **Slack tool-use** now surfaces in Devin Worklog with a dedicated icon and per-action detail view — visibility into Slack-driven actions Devin previously logged generically.
- Settings UI gains a centralized item registry with keyword search.
- Bug fixes: Devin Review commit-link URL formatting; default-branch detection (Devin had been indexing against an inferred branch rather than the actual GitHub/GitLab default in some repos).

### GitHub Copilot (May 6, 2026)

- **Enterprise-managed plugins for Copilot CLI** — public preview. IT admins distribute approved plugin sets via `.github-private/.github/copilot/settings.json`; Business and Enterprise users auto-install on auth. No price change.
- **Copilot CLI v1.0.42** — patches an MCP server failure path that previously surfaced as a generic startup warning.
- **VS Code April recap (v1.116–v1.119)** posted: workspace semantic search, repo/org-wide grep, incremental chat rendering, sortable agent sessions, synced session titles for Copilot CLI, experimental `/chronicle` query history, and **bring-your-own-model API keys** in Copilot Business/Enterprise VS Code chat — the first time Copilot has accepted user-supplied keys for non-Microsoft models.

## Key Themes

- **Two frontier defaults flipped in 24 hours**. GPT-5.5 Instant (May 5) replaced GPT-5.3 Instant for the bulk of ChatGPT traffic; Opus 4.7 (May 6) replaced Sonnet 4.6 as the Max/Team Premium default. Most of each vendor's install base is now on a different model family than they were on Monday morning, with no user action.
- **Code with Claude was a rate-limit and infrastructure event, not a model event**. Anthropic's announcements cluster around capacity (SpaceX / Colossus 1, doubled limits, peak-hour caps removed) and surface area (Code Review, Remote Agents, Agent SDK). The model is the same Opus 4.7 GA'd three weeks ago — the bottleneck has shifted from quality to tokens-per-user.
- **Devin's review surface is going horizontal**. Cognition shipped Devin Review *inside Windsurf* on the same day Devin's own product added Slack tool-use Worklog visibility. The pattern matches Devin 2.2 last week (Full Desktop Testing) — Cognition is racing to make Devin a layer that other IDEs *embed*, not a standalone competing IDE.
- **The agent-SDK layer is heating up**. anthropic-sdk-python v0.100.0 explicitly adds Managed Agents multi-agent and webhook APIs the same week OpenHands' agent-sdk and LangChain 1.3.0a2 both ship streaming-protocol upgrades. The race for the de-facto "agent runtime" abstraction is now visible in Pythonic SDKs, not just in headline products.
- **GitHub Copilot quietly accepted BYOK**. Bring-your-own-model API keys for Business/Enterprise VS Code chat is a small line in the April recap but a meaningful policy reversal — Copilot has historically routed everything through Microsoft-managed inference. Customers can now pay Anthropic, Google, or OpenAI directly while using Copilot's IDE surface.
