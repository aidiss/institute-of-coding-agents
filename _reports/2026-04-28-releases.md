# Releases — 2026-04-28

## Models

### Google DeepMind — Gemma 4

- **Gemma 4** — GA (April 2, 2026). Apache 2.0 license. Four dense variants led by a 31B model that outperforms models 20× its size on several benchmarks. Features 256K context windows, native vision and audio processing, and 140+ language fluency. Positioned as the most capable open-weight multimodal model for self-hosted deployment. Available on Hugging Face.

### Zhipu AI — GLM-5.1

- **GLM-5.1** — GA (April 7, 2026). Released by Z.ai. Posted 58.4 on SWE-Bench Pro, surpassing GPT-5.4 (57.7) and Claude Opus 4.6 (57.3). Marks the highest open/semi-open SWE coding score at time of launch.

### Anthropic — Claude Opus 4.7

- **Claude Opus 4.7** — GA (April 16, 2026). Anthropic's new flagship. Designed for complex reasoning and long-running agent workflows. Available to Claude Pro and Max subscribers. API pricing unchanged from Opus tier; exact token rates not publicly announced at launch.

### OpenAI — GPT-5.5

- **GPT-5.5** — GA (April 23, 2026). Available to ChatGPT Plus, Pro, Business, and Enterprise. First fully retrained base model since GPT-4.5 — rebuilt architecture, pretraining corpus, and objectives. Natively omnimodal. Leads Terminal-Bench 2.0 at 82.7% and the Intelligence Index at 60. API pricing: **$5/$30 per million input/output tokens** (doubled from $2.50/$15). Powers the updated OpenAI Codex cloud agent via NVIDIA infrastructure.

## Products

### Cursor — Cursor 3

- **Cursor 3** — GA (April 2, 2026). Major version launch positioning as a fully agentic coding interface. Described as the most commercially significant product story of the month. Competing directly with Claude Code and the updated OpenAI Codex. Frontier models moved behind Max Mode for legacy Team/Enterprise plans, accelerating credit burn for heavy users.

### Devin (Cognition AI) — Enterprise Controls

- **Enterprise-Scoped Secrets** — GA (April 3, 2026). Admins manage secrets at enterprise level; automatically shared across all organizations.
- **Enterprise ACU Visibility Control** — GA (April 3). Admins control whether users see compute unit (ACU) usage data.
- **Enterprise MCP Registry Enforcement** — GA (April 3). Enforces an allowlist of approved MCP servers across all organizations.
- **Enterprise Build Pinning** — GA (April 3). Admins can pin specific Devin builds and roll back.
- **SSO Connection Picker** — GA (April 22, 2026). Organizations with multiple SSO connections for the same email domain now see an explicit picker on login.

### Cloudflare — Project Think

- **Project Think** — Announced (April 20, 2026). New primitives for building long-running agents on Cloudflare Workers: durable execution, sub-agents, sandboxed code execution, and persistent sessions. Open beta; no separate pricing announced beyond existing Workers plans.

### Emergent — Wingman

- **Wingman** — Launched (April 15, 2026). New entrant. Indian vibe-coding startup Emergent (previously known for its no-code platform) launched Wingman, a messaging-first autonomous coding agent that runs in the background to complete tasks. Targets the same category as Devin and OpenHands.

### GitHub Copilot — CLI Updates

- **Copilot CLI v1.0.35** (April 23, 2026): Added slash command tab-completion for arguments and subcommands.
- **Copilot CLI v1.0.36** (April 24, 2026): Added subcommand picker with selection indicator and improved error messages with direct links.

### Claude Code (Anthropic) — Operational Change

- **Prompt cache TTL shortened** — Server-side prompt cache reduced from 1 hour to 5 minutes. Discovered by users through logs and billing behavior; affects cost calculations for long agentic sessions.

### Microsoft — Agent Governance Toolkit

- **Agent Governance Toolkit** — GA. Seven-package open-source system for governing autonomous AI agents. Available free on GitHub and PyPI.

## Key Themes

- **Compressed frontier launches**: GPT-5.5 (April 23) and Claude Opus 4.7 (April 16) landed within 7 days of each other, forcing rapid benchmark reassessment across the industry.
- **Open-weight catches up on coding**: GLM-5.1's 58.4 SWE-Bench Pro score and Gemma 4's multimodal capabilities narrow the gap with closed frontier models for specific coding tasks.
- **Flat-rate era ending**: GitHub Copilot, Anthropic (cache TTL cut), and Cursor (Max Mode gates) all tightened limits or raised effective costs for heavy users in April 2026.
- **Enterprise hardening**: Devin's April batch focused entirely on enterprise admin controls — secrets, SSO, MCP allowlists, build pinning — signaling a shift toward compliance-readiness.
- **New entrants from emerging markets**: Emergent's Wingman represents the first well-publicized India-origin autonomous coding agent to enter the competitive field.
