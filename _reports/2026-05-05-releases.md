# Releases — 2026-05-05

## Models

### xAI — Grok 4.3

- **Grok 4.3** — GA (released May 2–3, 2026). Carries over the 16-agent Heavy system and 1M-token context from Grok 4.20. New additions: native video input (first in the Grok lineup), longer training runs with improved context retention across agentic sessions, and structured document output (slides, PDFs, spreadsheets) directly in conversation.
- **Pricing**: $1.25/$2.50 per million input/output tokens — a ~40% cut versus Grok 4.20. Positions as the lowest-priced always-on reasoning model at 1M context.
- **Custom Voices API**: Shipped alongside the model. Clone a voice from ~1 minute of audio in under two minutes; 80+ preset voices across 28 languages; live passphrase + speaker-embedding match required for cloning (xAI's anti-spoofing claim; no published third-party red-team results). Free on the xAI console; shares TTS/voice-agent APIs with existing presets.

### Gemini — Flash Live improvements

- **Gemini 3.1 Flash Live** — incremental quality improvements rolled out in May 2026, targeting reliability for voice-first agents completing multi-step tasks. No version bump; improvements pushed to the existing model endpoint on Vertex AI and AI Studio.

## Products

### Anthropic — Claude Security (public beta)

- **Claude Security** — Public beta (announced April 30, broader rollout May 1, 2026). Purpose-built codebase vulnerability scanner powered by Claude Opus 4.7. Available to Claude Enterprise customers.
- Scans across files and modules, traces data flows, and delivers per-finding reports with confidence level, severity, likely impact, and steps to reproduce. Generates patch instructions reviewable in context.
- Supports directory-scoped scans, finding dismissal with documented reasons, CSV/Markdown export, and webhook delivery to Slack, Jira, and other tools.
- **Partner integrations**: CrowdStrike, Microsoft Security, Palo Alto Networks, SentinelOne, TrendAI, Wiz; services delivery via Accenture, BCG, Deloitte, Infosys, PwC.
- Previously in limited research preview as "Claude Code Security"; hundreds of organizations had early access before this broader rollout.

## Open Source

### Aider — Model support updates

- **Aider** (latest release, Apache 2.0) added support for **Claude Sonnet 4 / Opus 4** series (`claude-sonnet-4-20250514`, `claude-opus-4-20250514`) and updated the default `sonnet` / `opus` aliases. Added `vertex_ai/gemini-2.5-flash-preview-05-20`. Default OpenRouter onboarding models updated: `deepseek/deepseek-r1:free` (free tier) and `anthropic/claude-sonnet-4` (paid tier). GitHub Copilot tokens now auto-refresh when used as OpenAI API keys.
- Available on PyPI; changelog at [aider.chat/HISTORY.html](https://aider.chat/HISTORY.html).

## Key Themes

- **Aggressive API pricing from xAI**: Grok 4.3 at $1.25/$2.50/M tokens undercuts most comparable always-on reasoning models significantly. Bundles voice cloning as a free console feature — unusual for a frontier-lab API launch.
- **Security as a standalone product**: Claude Security represents Anthropic's first purpose-built enterprise vertical outside the core chat/API surface, shipping just weeks after Claude Opus 4.7 GA. Timing suggests Opus 4.7's code analysis capabilities were a prerequisite.
- **Open-source tooling absorbs frontier models within days**: Aider picked up Claude Sonnet 4 / Opus 4 support on a sub-week cadence after GA. The gap between frontier-model release and open-source tool support is now essentially zero.
