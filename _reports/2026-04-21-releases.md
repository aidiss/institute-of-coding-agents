# Releases — 2026-04-21

## Models

### Anthropic — Claude

- **Claude Opus 4.7** — GA (April 16, 2026). Available on Claude.ai, API, Amazon Bedrock, Google Vertex AI, Azure Foundry, Snowflake Cortex, and GitHub Copilot.
  - **High-resolution vision**: First Claude model with 2,576px / 3.75MP max image resolution (up from prior ceiling).
  - **Task budgets**: New parameter gives Claude a token estimate for the full agentic loop (thinking + tool calls + output), reducing runaway sessions.
  - **xhigh effort level**: New effort tier for extended reasoning on hard tasks.
  - **Benchmarks**: SWE-bench Verified 87.6% (up from Opus 4.6's 80.8%), CursorBench 70%, GPQA Diamond 94.2%.
  - **Context / output**: 1M-token context, 128k max output, adaptive thinking — same as Opus 4.6.
  - **Pricing**: Unchanged at $5 / $25 per million input / output tokens.

### Google DeepMind — Gemma

- **Gemma 4** — GA (April 2, 2026). Apache 2.0. Four-size family: E2B (2.3B effective), E4B (4.5B effective), 26B MoE (4B active parameters), 31B dense.
  - 256K context window; native vision and audio; fluent in 140+ languages.
  - 4× faster and up to 60% lower battery draw than Gemma 3.
  - Flagship 31B instruction-tuned model ranks #3 on Arena AI text leaderboard (1,452 Elo); 26B MoE ranks #6 (1,441 Elo), outperforming models 20× its size on several tasks.
  - Designed for on-device and agentic workloads; AICore developer preview available for Android.

### Meta — Llama 4

- **Llama 4 Scout** and **Llama 4 Maverick** — GA (April 5, 2026). Open-weight on Hugging Face and llama.com.
  - First open-weight natively multimodal (text, images, video) models with MoE architecture.
  - **Scout**: 17B active parameters, 16 experts, industry-leading 10M-token context window.
  - **Maverick**: 17B active parameters, 128 experts, 400B total parameters. Outperforms GPT-4o and Gemini 2.0 Flash on multimodal benchmarks; comparable to DeepSeek V3 on reasoning/coding at half the active parameters.

### Meta — Muse Spark

- **Muse Spark** — GA (April 8, 2026). Meta's first proprietary frontier model — closed weights, no open release. Positioned as a complement to the open Llama 4 family for use cases where Meta retains model control.

## Products

### Cursor (Anysphere)

- **Cursor 3** — Launched April 2, 2026. Full agent-first redesign.
  - **Agents Window**: Run many agents in parallel across local, git worktree, cloud, and remote SSH environments in one view.
  - **Design Mode**: Annotate and target UI elements directly in a live browser window for precise visual iteration.
  - **Agent Tabs**: View multiple chats side-by-side or in a grid.
  - **`/worktree` command**: Creates an isolated git worktree so agent changes don't pollute the main branch.
  - **Multi-repo layout**: Cleaner interface with seamless local-to-cloud agent handoff.
  - **Composer 2**: Anysphere's proprietary coding model, co-shipped with Cursor 3. CursorBench score 61.3 (+39% vs Composer 1.5), running at 200+ tokens per second.

### Windsurf (Google / Codeium)

- **Windsurf 2.0** — GA (April 15, 2026). Major release post-Google acquisition.
  - **Agent Command Center**: Kanban-style view of all running agents across local and cloud environments — grouped by status (active, blocked, complete) with in-place manual editing.
  - **Spaces**: Project-scoped workspaces that group agent sessions, PRs, files, and context; persisted across sessions.
  - **Devin integration**: Cognition's Devin cloud agent is now accessible inside the IDE. Operates in its own VM with desktop, browser, and computer-use capabilities; can continue work after the laptop is closed.
  - **Adaptive model**: New model picker option that auto-selects the best model per task to reduce quota consumption.
  - **GPT-5.1 and GPT-5.1-Codex**: Both models now available in Windsurf; GPT-5.1 is the default for paid users for a limited period.

### GitHub Copilot CLI (Microsoft)

- **v1.0.32** — April 17, 2026. Allows short session ID prefixes (7+ hex chars) with `--resume` and `/resume` instead of the full UUID.
- **v1.0.31** — April 16, 2026. Fixes prompt frame rendering issues on Windows and Ubuntu terminals.
- **v1.0.30** — April 16, 2026. Fixes feedback form links.

### Claude Code (Anthropic)

- Smoother fullscreen scrolling in VS Code, Cursor, and Windsurf terminal integrations.
- Improved thinking spinner: now shows inline progress messages ("still thinking", "thinking more", "almost done thinking") rather than a static indicator.

## Key Themes

- **IDE generation shift**: Cursor 3 and Windsurf 2.0 both shipped within two weeks of each other, each rebuilding the UX from "chat with context" to "orchestrate parallel agents." The IDE is becoming a control plane.
- **Devin goes ambient**: Windsurf's Devin integration means truly background execution (work continues when the laptop closes) is now available inside a mainstream IDE.
- **Claude Opus 4.7 raises the SWE-bench ceiling**: 87.6% is the new high-water mark for a commercial model; context and output limits unchanged but vision and task budgets address two persistent pain points in agentic loops.
- **Meta bets both ways**: Llama 4 (open-weight) and Muse Spark (proprietary) released in the same week — Meta is hedging between open ecosystem leadership and closed-model monetization.
- **Gemma 4 on-device**: Google's Apache 2.0 release targeting Android AICore signals a push to put capable multimodal models directly on handsets.
