# Releases — 2026-04-30

## Models

### Meta — Llama 4 Scout & Maverick

- **Llama 4 Scout** — GA / open-weight (April 5, 2026). 17B active parameters, 16 experts, MoE architecture. Industry-leading 10M-token context window. Natively multimodal (text + images, no separate vision encoder). Available on Hugging Face and llama.com under Meta's open-use license. Outperforms Gemma 3, Gemini 2.0 Flash-Lite, and Mistral 3.1 on broad benchmarks.
- **Llama 4 Maverick** — GA / open-weight (April 5, 2026). 17B active parameters, 128 experts, MoE architecture. 1M-token context window. Benchmark claim: beats GPT-4o and Gemini 2.0 Flash across multimodal tasks; comparable to DeepSeek v3 on reasoning and coding. Both are the first open-weight natively multimodal MoE models from Meta.

### Anthropic — Claude Opus 4.7

- **Claude Opus 4.7** — GA (April 16, 2026). Meaningful gains on advanced software engineering and long-horizon agentic tasks versus Opus 4.6. First Claude model with high-resolution image support: maximum image resolution raised to 2576px / 3.75MP. Pricing unchanged at $5.00 / $25.00 per 1M input/output tokens. Context window: 1M tokens. Available on Anthropic API, Amazon Bedrock, Google Cloud Vertex AI, and Microsoft Foundry. Became the default model for Claude Code on April 23.

## Products

### Anthropic — Claude Code

- **Claude Opus 4.7 as default** — Effective April 23, 2026. Achieves 87.6% on SWE-bench Verified and 64.3% on SWE-bench Pro. Claude Code shipped over 30 releases during the March–April 2026 iteration cycle.

### GitHub — Copilot & Copilot CLI

- **Claude Opus 4.7 rolling out to GitHub Copilot** — Starting April 16, 2026. Claude Opus 4.7 is being introduced to Copilot Pro+ and will replace Opus 4.5/4.6 in the model picker over coming weeks. Launching with a 7.5× premium request multiplier under promotional pricing through April 30, 2026.
- **Model selection for Claude and Codex agents on github.com** — Released April 14, 2026. Users can now choose a specific model when kicking off an agentic task: Anthropic models for Claude, OpenAI models for Codex.
- **Copilot CLI v1.0.37** — Released April 27, 2026. Location-based permission persistence is now enabled by default, so approvals carry over across sessions for the same working directory.
- **Copilot CLI v1.0.39** — Released April 28, 2026. Adds toggle for allow-all permission mode via session config; introduces slash commands `/compact`, `/context`, `/usage`, and `/env`.

### Meta — LlamaCon / Llama API

- **Llama API** — Limited preview (April 29, 2026, at LlamaCon). Combines open-source flexibility with a managed API endpoint. Features one-click API key creation and interactive model playgrounds. Llama 4 Scout and Maverick are the launch models.
- **Llama Protection Tools & Defenders Program** — Announced April 29, 2026 at LlamaCon. AI-enabled red-teaming tools for evaluating system security; select partners gain early access through the Llama Defenders Program.

### Windsurf — Wave 13

- **Wave 13** — Released April 2026. SWE-1.5 access and parallel agents expanded to every pricing tier. SWE-1.5 is trained end-to-end with RL on real coding environments and runs at 950 tokens/second on Cerebras hardware (approx. 6× faster than Haiku 4.5). Minor version releases: v2.0.44 (April 15), v2.0.50 (April 16), v2.0.61 (April 17).

## Open Source

### OpenCode

- **OpenCode** — Growth milestone (April 2026). The Go-based, provider-agnostic terminal coding agent (supports 75+ LLM providers including local models via Ollama) crossed 147,000 GitHub stars and 6.5 million monthly active developers. Up from 100K stars and 2.5M devs in February 2026; growing 4.5× faster than Claude Code in star velocity. MIT-licensed. GitHub: [opencode-ai/opencode](https://github.com/opencode-ai/opencode).

### OpenHands

- **OpenHands v1.6.0** — Released March 30, 2026 (most recent stable as of April 30). New: support for hooks (pre/post action callbacks) and Catalan language localization. MIT-licensed. 68K GitHub stars. The cloud-hosted platform (openhands.dev) continues to operate in parallel with the self-hosted CLI/GUI path.

## Key Themes

- **Open-weight multimodal MoE arrives**: Llama 4 Scout and Maverick mark the first time a frontier-grade open-weight MoE model ships with native multimodality, closing a meaningful capability gap between open and closed models.
- **Opus 4.7 as the new agentic baseline**: Its adoption as the Claude Code default — and its rapid rollout across Bedrock, Vertex, Foundry, and Copilot — signals that Anthropic is anchoring the entire ecosystem around a single coding-optimized model.
- **LlamaCon as platform moment**: Meta used its first developer conference to shift Llama from a weights-only download toward a managed API surface, directly competing with OpenAI and Anthropic on API convenience.
- **Terminal agents accelerating**: OpenCode's star velocity shows sustained developer appetite for lightweight, provider-agnostic, locally-runnable alternatives to IDE-heavy tools.
