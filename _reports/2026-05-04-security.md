## Incidents & Vulnerabilities

### "Comment and Control" — Prompt Injection Across Claude Code, Copilot, Gemini CLI
Researchers demonstrated that injecting adversarial instructions inside code comments causes Claude Code, GitHub Copilot Agents, and Gemini CLI to leak secrets or execute unintended commands. Three tools were exploited in a single audit; Anthropic's own system card for Claude Code acknowledged the GitHub Action review feature is "not hardened against prompt injection" and classified the finding **CVSS 9.4 Critical**. Status: **disclosed, partial mitigations; not fully patched**.
- Sources: [VentureBeat](https://venturebeat.com/security/ai-agent-runtime-security-system-card-audit-comment-and-control-2026), [SecurityWeek](https://www.securityweek.com/claude-code-gemini-cli-github-copilot-agents-vulnerable-to-prompt-injection-via-comments/)

### CVE-2026-25723 — Claude Code Sandbox Escape (File-Write Bypass)
Piped `sed` and `echo` command chains bypassed Claude Code's file-write restrictions, allowing escape from the project sandbox because command chaining was not validated. Status: **disclosed**.

### CVE-2026-33068 — Claude Code Trust-Prompt Bypass
Malicious repositories could set permission flags to suppress trust dialogs entirely, silently granting elevated access. Status: **disclosed**.

### CVE-2026-21516 — GitHub Copilot for JetBrains Command Injection (CVSS 8.8)
Affects Copilot for JetBrains versions 1.0.0–1.5.62. A command injection vulnerability enabled arbitrary code execution. Status: **patched**.

### CVE-2025-53773 — GitHub Copilot Hidden Prompt Injection via PR Descriptions (CVSS 9.6)
Hidden prompt injection in pull request descriptions triggered RCE via Copilot Workspace. Separately, the "CamoLeak" variant (CVSS 9.6) used invisible Unicode characters for silent code exfiltration. Status: **disclosed**.
- Also: CVE-2025-62449, CVE-2025-62453 (path traversal and code injection in Copilot).

### CVE-2025-54135 — Cursor Untrusted MCP RCE (CVSS 8.6)
Untrusted MCP server connections in Cursor led to remote code execution. Patched in **Cursor 1.3**. Status: **patched**.

### Google Antigravity (AI IDE) — Critical RCE
A prompt injection proof-of-concept triggered sandbox escape and RCE in Google's Antigravity agentic IDE. Google issued a fix; no CVE number published at time of writing. Status: **patched**.
- Source: [Dark Reading](https://www.darkreading.com/vulnerabilities-threats/google-fixes-critical-rce-flaw-ai-based-antigravity-tool)

### Credential Theft Wave — Codex, Claude Code, Copilot Breached (Apr 2026)
A nine-month streak of attacks targeted AI coding agent credentials rather than model logic. Attackers located tokens held by the agent and used them to access production systems. ~78% of organizations run AI agents with unmanaged production credentials (Gravitee 2026 survey; only 21.9% enrolled agent creds into a PAM system). Status: **actively exploited pattern**.
- Sources: [VentureBeat](https://venturebeat.com/security/six-exploits-broke-ai-coding-agents-iam-never-saw-them), [Softtechhub](https://softtechhub.us/2026/04/30/codex-claude-code-and-copilot-breached/)

### Windsurf 1.9544.26 — Prompt Injection → Arbitrary Command Execution
Remote attackers can execute arbitrary commands on victim systems via prompt injection. Status: **disclosed**.

## Supply Chain

### MCP Design-Level RCE — CVE-2025-49596, CVE-2026-22252, CVE-2026-22688, CVE-2025-54994, CVE-2025-54136
Researchers identified an architectural flaw in Anthropic's Model Context Protocol: the STDIO interface allows arbitrary OS command execution across all official MCP SDKs (Python, TypeScript, Java, Rust). This is a design decision, not a coding bug. Anthropic confirmed the behavior is intentional and declined to change the protocol, stating sanitization is the developer's responsibility.

Affected scope: **150 million+ downloads, 7,000+ publicly accessible servers, ~200,000 vulnerable instances, 200+ open source projects**. Characterized by researchers as "the AI equivalent of Log4Shell." Status: **disclosed, no upstream fix; mitigations are implementation-specific**.
- Sources: [The Hacker News](https://thehackernews.com/2026/04/anthropic-mcp-design-vulnerability.html), [OX Security](https://www.ox.security/blog/mcp-supply-chain-advisory-rce-vulnerabilities-across-the-ai-ecosystem/), [The Register](https://www.theregister.com/2026/04/16/anthropic_mcp_design_flaw/), [Infosecurity Magazine](https://www.infosecurity-magazine.com/news/systemic-flaw-mcp-expose-150/)

### Slopsquatting — AI Hallucinated Package Names Weaponized
Threat actors register package names that AI coding agents hallucinate on PyPI and npm. Research on 576,000 generated Python/JS samples found ~20% recommended non-existent packages; 58% of hallucinated names are consistent across repeated runs, making them reliable targets. Autonomous coding agents (Cursor, Claude Code, Copilot Workspace) can install these packages without human review. Status: **actively exploited pattern; no systemic fix**.
- Sources: [BleepingComputer](https://www.bleepingcomputer.com/news/security/ai-hallucinated-code-dependencies-become-new-supply-chain-risk/), [Infosecurity Magazine](https://www.infosecurity-magazine.com/news/ai-hallucinations-slopsquatting/), [Snyk](https://snyk.io/articles/slopsquatting-mitigation-strategies/), [Security Boulevard](https://securityboulevard.com/2026/03/coding-agents-widen-your-supply-chain-attack-surface/)

### Automated Dependency Side-Loading via AI Extensions
A related attack class involves VS Code / IDE extension manifests being injected with dependency overrides that AI agents propagate during automated refactoring runs.
- Source: [Medium / InstaTunnel](https://medium.com/@instatunnel/automated-dependency-side-loading-the-invisible-supply-chain-attack-via-ai-extensions-fe615eb03f19)

### AI-Generated Code CVE Surge
35 new CVEs disclosed in March 2026 were directly attributed to AI-generated code (up from 6 in January and 15 in February), indicating a growing pipeline of vulnerabilities introduced by AI-assisted development.
- Source: [Infosecurity Magazine](https://www.infosecurity-magazine.com/news/ai-generated-code-vulnerabilities/)

## Research & Advisories

### OWASP: Prompt Injection in 73% of Production AI Deployments
OWASP's 2026 security audit data indicates prompt injection is present in over 73% of production AI deployments assessed. The LLM Top 10 continues to list prompt injection and insecure output handling as the top two risks for LLM-integrated applications.

### Unit 42 — New MCP Sampling Attack Vectors
Palo Alto Unit 42 published research on novel prompt injection vectors through MCP's sampling feature, enabling exfiltration of context windows and tool invocation manipulation.
- Source: [Unit 42 / Palo Alto](https://unit42.paloaltonetworks.com/model-context-protocol-attack-vectors/)

### VulnerableMCP.info — Community CVE Database for MCP
A community-maintained database tracking security vulnerabilities specific to MCP implementations has launched at vulnerablemcp.info.
- Source: [vulnerablemcp.info](https://vulnerablemcp.info/)

### "92% of AI Code Has Critical Vulnerabilities" — 2026 Security Report
Sherlock Forensics published a 2026 report claiming 92% of audited AI-generated codebases contained at least one critical vulnerability, predominantly SQL injection, SSRF, and path traversal.
- Source: [Sherlock Forensics](https://www.sherlockforensics.com/pages/ai-code-security-report-2026.html)

### Cymulate: Sandbox Escape Research Series
Cymulate published "The Race to Ship AI Tools Left Security Behind" (Part 1: Sandbox Escape), analyzing how time-to-market pressure led to inadequate isolation in multiple coding agent products.
- Source: [Cymulate](https://cymulate.com/blog/the-race-to-ship-ai-tools-left-security-behind-part-1-sandbox-escape/)
