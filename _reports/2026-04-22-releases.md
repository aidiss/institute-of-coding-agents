# Releases — 2026-04-22

## Models

### Anthropic — Claude

- **Claude Opus 4.7** — GA (April 16, 2026). Available on Claude.ai, API, Amazon Bedrock, Google Vertex AI, Microsoft Foundry, Snowflake Cortex, and GitHub Copilot.
  - **High-resolution vision**: First Claude model with 2,576px / 3.75MP max image resolution (previously 1,568px / 1.15MP).
  - **Task budgets**: New parameter gives Claude a running token countdown for the full agentic loop (thinking + tool calls + output), reducing runaway sessions.
  - **New tokenizer**: May use 1×–1.35× as many tokens on text content compared to prior models; improves performance on structured and multilingual input.
  - **Cybersecurity safeguards**: Automatic detection and blocking of prohibited high-risk cybersecurity requests built into the model layer.
  - **Benchmarks**: SWE-bench Verified 87.6% (up from Opus 4.6's 80.8%); GPQA Diamond 94.2%.
  - **Pricing**: Unchanged — $5 / $25 per million input / output tokens.

### Google DeepMind — Gemma

- **Gemma 4** — GA (April 2, 2026). Apache 2.0. Four sizes: E2B (2.3B effective), E4B (4.5B effective), 26B MoE (4B active parameters), 31B dense.
  - 256K context window; native multimodal input (text, image, video, audio on smaller sizes); 140+ languages.
  - 31B instruction-tuned model ranks #3 on Arena AI text leaderboard (1,452 Elo); 26B MoE ranks #6 (1,441 Elo).
  - Designed for on-device and agentic workloads; AICore developer preview available for Android.
  - `ollama run gemma4` installs locally in a single command.

### Meta — Llama 4

- **Llama 4 Scout** and **Llama 4 Maverick** — GA (April 5, 2026). Open-weight on Hugging Face and llama.com.
  - First open-weight natively multimodal (text, images, video) MoE models from Meta.
  - **Scout**: 17B active / 109B total parameters; 16 experts; 10M-token context window.
  - **Maverick**: 17B active / 400B total parameters; 128 experts; fits on a single H100 host. Outperforms GPT-4o and Gemini 2.0 Flash on multimodal benchmarks; comparable to DeepSeek V3 on reasoning/coding.

### Meta — Muse Spark

- **Muse Spark** — GA (April 8, 2026). Meta's first proprietary closed-weight frontier model, released alongside the open Llama 4 family.

## Products

### Cursor (Anysphere)

- **Cursor 3** — GA (April 2, 2026). Full agent-first redesign.
  - **Agents Window**: Run many agents in parallel across local, git worktree, cloud, and remote SSH environments from one view.
  - **Design Mode**: Annotate and target live browser UI elements for visual iteration.
  - **Composer 2**: Anysphere's proprietary coding model co-shipped with Cursor 3; CursorBench score 61.3 (+39% vs Composer 1.5), 200+ tokens/sec.
  - Cursor crossed $1B ARR milestone during Q1 2026.

### Windsurf (Google / Codeium)

- **Windsurf 2.0** — GA (April 15, 2026). Major release post-Google acquisition.
  - **Agent Command Center**: Kanban-style view of all running agents across local and cloud environments, grouped by status with in-place manual editing.
  - **Spaces**: Project-scoped workspaces grouping agent sessions, PRs, files, and context — persisted across sessions.
  - **Devin integration**: Cognition's Devin cloud agent accessible inside the IDE, operating in its own VM; continues working after the laptop is closed.
  - Current build: v2.0.61 (April 17, 2026).

### GitHub Copilot CLI (Microsoft)

- **v1.0.32** — April 17, 2026. Short session ID prefixes (7+ hex chars) now accepted with `--resume` and `/resume`.
- **v1.0.31** — April 16, 2026. Fixes prompt frame rendering on Windows and Ubuntu terminals.
- GitHub Copilot passed 4.7M paid subscribers and 90% of Fortune 100 adoption as of April 2026.

### Gemini CLI (Google)

- **Subagents integration** — April 2026. Google embedded subagent dispatch directly into Gemini CLI, turning the terminal into a multi-agent dispatch center. Developers use `@agent` syntax to delegate work to specialized expert agents from the command line.
- Additional April updates: TerminalBuffer mode (eliminates flicker on long agent turns), compact tool output as default rendering, context-aware policy approvals (approve a tool once per folder), memory service extracting reusable patterns across sessions.
- Open-source under Apache 2.0 at `github.com/google-gemini/gemini-cli`. Free tier via personal Google account with access to Gemini 2.5 Pro.

### OpenAI Agents SDK

- **Next evolution** — GA (April 15–17, 2026). Major update targeting enterprise agentic workflows.
  - **Native sandbox execution**: Agents can run in controlled compute environments with filesystem tools, dependency installation, and command execution out of the box.
  - **Sandbox providers**: Built-in support for Blaxel, Cloudflare, Daytona, E2B, Modal, Runloop, and Vercel; bring-your-own also supported.
  - **Model-native harness**: Configurable memory, sandbox-aware orchestration, Codex-style filesystem tools; compatible with any Chat Completions-compatible endpoint (100+ non-OpenAI models).
  - Python GA; TypeScript support planned. Standard API pricing applies.

### Salesforce — Headless 360

- **Headless 360** — GA (April 16, 2026, announced at TDX developer conference). Exposes the entire Salesforce platform as an API, MCP tool, or CLI command so AI agents (Claude Code, Cursor, Codex) can build and operate on Salesforce without opening a browser. Shipped 100+ new tools and skills at launch.

### Claude Code (Anthropic)

- Claude Sonnet 4.6 is the current default model.
- Improved thinking spinner with inline progress messages ("still thinking", "thinking more", "almost done thinking") rather than a static indicator.
- Smoother fullscreen scrolling in VS Code, Cursor, and Windsurf terminal integrations.

## Key Themes

- **Subagent dispatch goes mainstream**: Both Gemini CLI and OpenAI's Agents SDK shipped dedicated subagent/sandbox infrastructure this week, signaling that multi-agent orchestration is now a platform-level expectation rather than a niche feature.
- **Open terminal agents converging**: Gemini CLI and OpenCode are pushing capable, Apache 2.0 / open alternatives to proprietary CLIs; Google's free Gemini 2.5 Pro tier makes Gemini CLI a credible zero-cost entry point.
- **Platform integrations accelerating**: Salesforce Headless 360 follows a pattern of enterprise platforms exposing MCP / CLI surfaces so AI agents can drive them — the IDE is increasingly a control plane over the entire software supply chain.
- **Cursor 3 + $1B ARR**: The $1B ARR milestone during the same quarter as the Cursor 3 launch makes it the fastest-growing developer tool on record; Windsurf 2.0 and GitHub Copilot's 4.7M subscribers show the competitive pressure is intensifying across all tiers.
