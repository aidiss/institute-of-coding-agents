# Releases — 2026-04-25

## Models

### OpenAI — GPT-5.5

- **GPT-5.5** — GA (released April 23, 2026). Internally codenamed "Spud". Designed around agentic work: switches between multiple tools autonomously to carry complex tasks to completion. Strongest gains in agentic coding, computer use, knowledge work, and scientific research. GPT-5.5 Pro variant also shipping for Pro/Business/Enterprise users.
- API available as of April 24, 2026 (one day after ChatGPT rollout).
- Pricing: $5/$30 per million tokens (input/output) — double GPT-5.4's input price; OpenAI states the model is substantially more token-efficient, offsetting effective cost.
- Available to: ChatGPT Plus, Pro, Business, Enterprise; Codex; API. Rolling out broadly through end of month.

### DeepSeek — DeepSeek V4 (Preview)

- **DeepSeek V4-Flash** and **DeepSeek V4-Pro** — Preview released April 24, 2026. Open-source and open-weights. Long-awaited successor to V3.2.
- Architecture: Mixture-of-Experts with a new **Hybrid Attention Architecture** improving long-context recall. Context window: **1 million tokens**.
- V4-Pro: 1.6T total / 49B active parameters. V4-Flash: 284B total / 13B active parameters.
- Benchmark claim: "closes the gap" with current frontier models on reasoning, coding, and agentic tasks; open-source SOTA on agentic coding benchmarks.
- Pricing (API): Flash — $0.14/$0.28 per million tokens; Pro — $1.74/$3.48 per million tokens.
- Available at chat.deepseek.com (Expert Mode / Instant Mode) and via DeepSeek API. Weights open-sourced.
- Tight integration with Huawei's Ascend chips announced alongside release.

### Anthropic — Claude Opus 4.7

- **Claude Opus 4.7** — GA (released April 16, 2026; included here as it falls within the past week). Targets complex, long-running agent workflows; notable gains on the hardest software engineering tasks. Improved vision: higher-resolution image understanding.
- Includes new **Cyber Verification Program**: security professionals (pen testers, red teamers, vuln researchers) can apply for verified access to bypass the automatic cybersecurity-use safeguards bundled in this release.
- Pricing: unchanged from Opus 4.6 — $5/$25 per million tokens (input/output).
- Available: Claude.ai, API, Amazon Bedrock, Google Cloud Vertex AI, Microsoft Foundry, GitHub Models.

## Products

### OpenAI — Workspace Agents in ChatGPT

- **ChatGPT Workspace Agents** — GA for Business, Enterprise, and Education tiers (rolled out alongside GPT-5.5 this week). Teams can build, share, and deploy custom agents that operate across Slack, Gmail, and other connected tools. Positions ChatGPT closer to an AI "super app" combining chat, coding, and cross-tool automation.

### OpenAI — Codex with GPT-5.5

- **Codex** updated to run GPT-5.5 as its default cloud coding model. No separate product launch; the model upgrade is automatic for existing Codex users on eligible ChatGPT plans.

### Windsurf (Cognition AI) — SWE-1.5 + Cascade Hooks

- **SWE-1.5** — Windsurf's latest proprietary coding model, running at ~950 tokens/second on Cerebras hardware. Positioned as a speed-first alternative for real-time agentic coding.
- **Cascade Hooks** — New workflow automation layer; allows external events (CI results, issue tracker updates) to trigger Cascade agents directly.
- Context: Cognition AI (the Devin team) acquired Windsurf for ~$250M. Windsurf Pro remains $15/month; free plan now includes parallel agents.

## Open Source

### DeepSeek V4

- **DeepSeek V4-Flash / V4-Pro** — Open-source weights released April 24, 2026 (same day as the product preview, above). Available on Hugging Face. Previous report (2026-04-02) flagged V4 as still pending; it has now shipped.
- MIT-compatible licensing. Weights can be self-hosted; Huawei Ascend deployment guides included.

### Aider

- Minor maintenance release in the April window. Notable additions: **Scala repomap support** (tree-sitter); `Ctrl-X Ctrl-E` keybinding to open the current input buffer in an external editor; web scraping timeout demoted from error to warning (allows partial content). No major version bump.
- Apache 2.0; self-hosted, terminal-based.

## Key Themes

- **GPT-5.5 and DeepSeek V4 arrive within 48 hours**: The two most anticipated releases of the quarter both land in the same week, representing both the frontier closed-source (OpenAI) and open-source (DeepSeek) positions simultaneously advancing.
- **DeepSeek V4 erases prior frontier gap narrative**: The previous reporting window (April 2) noted DeepSeek V4 was still pending while V3.2 held. V4-Pro's claimed near-frontier parity on reasoning benchmarks — at $1.74/M input — resets price-performance expectations again.
- **Agentic framing now standard**: GPT-5.5, Opus 4.7, Windsurf SWE-1.5, and DeepSeek V4 all lead with agentic capabilities rather than chat performance. Benchmark differentiation has shifted to SWE-bench and computer-use, not MMLU.
- **OpenAI pricing parity with Anthropic**: GPT-5.5 at $5/$30 and Opus 4.7 at $5/$25 are effectively at the same input price tier; output costs diverge modestly. Enterprise buyers are now choosing on capability and workflow integration rather than price.
- **1M-token context becomes table stakes**: DeepSeek V4 ships with 1M context; Llama 4 Scout already there. Providers without million-token context are increasingly differentiated downward.
