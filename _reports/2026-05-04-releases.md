# Releases — 2026-05-04

## Models

### Anthropic — Claude Opus 4.7

- **Claude Opus 4.7** — GA (released April 16, 2026). Substantially improved software engineering on hard tasks; better vision with higher-resolution image understanding; more tasteful creative output (interfaces, slides, docs). Pricing unchanged from 4.6: $5/M input, $25/M output. Available across Claude.ai, API, Amazon Bedrock, Google Vertex AI, and Microsoft Foundry.
- Shipped alongside **Claude Design** (research preview, April 17) — a text-to-prototype tool powered by Opus 4.7, available to Pro/Max/Team/Enterprise subscribers. Creates slides, one-pagers, and interactive prototypes from prompts or briefs. Figma stock fell ~5–7% on announcement day.

### OpenAI — GPT-5.5 ("Spud")

- **GPT-5.5** — GA (released April 23, 2026; API available April 24). Codename "Spud." Rolling out to Plus, Pro, Business, and Enterprise on ChatGPT and Codex; GPT-5.5 Pro for Pro/Business/Enterprise. Described as higher intelligence than GPT-5.4 while matching its per-token latency and using significantly fewer tokens on Codex tasks. Released with OpenAI's "strongest set of safeguards to date."

### DeepSeek — V4 (Preview)

- **DeepSeek V4** — Preview (released April 24, 2026). Two variants: **V4 Pro** (1.6T total / 49B active parameters) and **V4 Flash** (284B total / 13B active). Both ship with 1M token context window. **MIT licensed** — weights available on Hugging Face. Production-stable release timeline not announced.

### Mistral — Medium 3.5 and Voxtral TTS

- **Mistral Medium 3.5** — GA (April 2026). Mistral's new flagship; frontier-class multimodal model optimized for agentic and coding use cases. Adjustable reasoning via `reasoning_effort` parameter. Available via Mistral API (`mistral-medium-3.5`).
- **Voxtral TTS** — GA (April 2026). State-of-the-art text-to-speech with zero-shot voice cloning, multilingual support, and real-time streaming. Available via Mistral API (`voxtral-tts-2603`).

## Products

### Cursor — Cursor 3

- **Cursor 3** — GA (released April 2, 2026). Largest release since the VS Code fork. New **Agents Window**: run multiple agents in parallel across local machines, git worktrees, SSH, and cloud environments. **Design Mode**: annotate and target UI elements in the browser for precise agent feedback. **Agent Tabs**: view multiple chats side-by-side or in a grid. New `/worktree` command creates isolated git worktrees per agent. Access via `Cmd+Shift+P → Agents Window`.

### Windsurf — Windsurf 2.0

- **Windsurf 2.0** — GA (April 2026). Key additions: **Agent Command Center** — Kanban-style surface showing all agent sessions grouped by status. **Devin integration** — plan locally in Cascade, hand off to Devin cloud agent in one click for debugging, testing, and deployment on Devin's own VM with desktop, browser, and computer-use. **Spaces** — bundle agent sessions, PRs, files, and context around a single task for context-free task switching. **Adaptive model** — intelligently selects the best model per task to conserve quota. Pro plan increased from $15 to $20/month (matching Cursor). Also added GPT-5.5 and Claude Opus 4.7 to the model picker.

### GitHub Copilot CLI — v1.0.40

- **GitHub Copilot CLI 1.0.40** — GA (released May 1, 2026). Key fixes and additions: `client_credentials` OAuth grant for MCP servers (headless auth without browser), smoother streaming text output, `/clear` and `/new` reset active custom agent selection, subagents evaluate tool search support for their own model (not the parent's), fixed 100% CPU hang on large file attachments. `prompt` mode (`-p`) gates repo hooks and workspace MCP behind opt-in env vars for secure-by-default behavior.

### Microsoft — Agent 365

- **Microsoft Agent 365** — GA (launched May 1, 2026). Enterprise-grade control plane for agents, shipping alongside the Microsoft 365 E7 plan. Unified management surface for deploying, monitoring, and governing agents across the Microsoft 365 stack.

### DeepSeek V4 — Open Weights (MIT)

- DeepSeek V4 Pro and V4 Flash weights available on Hugging Face under **MIT license** from day one of the April 24 preview. V4 Pro at 1.6T parameters (49B active, MoE) is among the largest open-weight models currently available.

### Aider — Model Support Updates

- Recent releases added support for **Claude Sonnet 4 / Opus 4 series** (`claude-sonnet-4-20250514`, `claude-opus-4-20250514`) and updated default aliases accordingly. Added **Gemini 2.5 Pro/Flash** with thinking-token support (`flash` alias → `gemini-2.5-flash`). New `--add-gitignore-files` flag enables adding gitignored files to editing scope. Removed deprecated `google-generativeai` dependency. Apache 2.0; available on PyPI.

### Qwen 3.6 / 35B-A3B

- Qwen 3.6–35B-A3B (MoE architecture, ~3B active parameters) posting frontier-tier coding benchmark scores while running on consumer hardware. Open weights available; underscores continued narrowing between commercial and open-weight model performance on coding tasks.

## Key Themes

- **Parallel agents are the new baseline**: Cursor 3 (Agents Window), Windsurf 2.0 (Agent Command Center + Devin hand-off), and Claude Code (Agent Teams) all make running multiple concurrent agents the default workflow — not an advanced feature.
- **Model cadence compressing**: GPT-5.5 shipped six weeks after GPT-5.4; Claude Opus 4.7 arrived five weeks after Sonnet 4.6 GA. Frontier labs are now shipping significant model updates on a near-monthly schedule.
- **Open weights at scale**: DeepSeek V4 Pro (1.6T params, MIT) and Qwen 35B-A3B signal open-weight models have reached a competitive tier for coding workloads — the cost advantage of running self-hosted is now paired with near-frontier quality.
- **Anthropic expanding beyond chat**: Claude Design (text-to-prototype) and Claude Cowork (agentic knowledge work) represent Anthropic's first product moves outside the core chat/API offering, targeting Figma and productivity-suite use cases respectively.
- **Enterprise control planes arriving**: Microsoft Agent 365 and Windsurf's Agent Command Center reflect a maturing market where managing fleets of agents — not just using individual agents — is becoming a distinct product category.
