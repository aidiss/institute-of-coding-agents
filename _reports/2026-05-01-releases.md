# Releases — 2026-05-01

## Models

### OpenAI — GPT-5.5

- **GPT-5.5** — GA (April 23–24, 2026). Rolling out to ChatGPT Plus, Pro, Business, and Enterprise. Improvements in coding, computer use, and deep research over GPT-5.4. API available in Responses and Chat Completions APIs. Pricing: $5.00 / $30.00 per 1M input/output tokens; 1M context window. Batch/Flex pricing at 0.5×; Priority processing at 2.5×.
- **GPT-5.5 Pro** — GA alongside standard tier. Higher accuracy variant for Pro/Business/Enterprise ChatGPT tiers and API. API pricing: $30.00 / $180.00 per 1M input/output tokens.
- **GPT-5.5 GA for GitHub Copilot** — April 24, 2026. Available in the Copilot model picker for Copilot Pro+ and Business plans.

### DeepSeek — V4 Preview (Flash + Pro)

- **DeepSeek-V4-Flash** — Preview / open-weight (April 24, 2026). 284B total / 13B active parameters, MoE architecture. 1M-token context window, 384K max output. MIT license. Available via DeepSeek API and as open weights. Accessible via chat.deepseek.com (Instant Mode).
- **DeepSeek-V4-Pro** — Preview / open-weight (April 24, 2026). 1.6T total / 49B active parameters, MoE architecture. Same 1M context / 384K output specs. MIT license. Targets research, enterprise, and complex agentic tasks. Available via DeepSeek API and as open weights (chat.deepseek.com Expert Mode). Positioned as the cheapest frontier-grade model by token price at launch.

### xAI — Grok 4.3 Beta

- **Grok 4.3 Beta** — Restricted preview (April 17, 2026). Released without announcement; appeared silently in the model selector on grok.com and in iOS/Android apps. Access limited to SuperGrok Heavy subscribers ($300/month). Standard SuperGrok ($30/month) subscribers can see the model in the dropdown but cannot use it. Full rollout expected mid-to-late May 2026. New capabilities: native video input, in-chat slide generation.

### NVIDIA — Nemotron 3 Nano Omni

- **Nemotron 3 Nano Omni** — GA / open model (April 2026). Unified multimodal model handling video, audio, image, and text in a single system. Designed for on-device and edge agent deployments. Supports advanced reasoning across modalities with claimed up to 9× efficiency improvement for agentic workloads versus prior Nemotron versions.

### Microsoft — Three Foundational Models

- **MAI-1, MAI-DS, MAI-V** — GA (April 2, 2026). Three new foundational models covering text generation, domain-specialized reasoning, and image synthesis. Released in parallel as part of Microsoft AI's move to build first-party model capabilities alongside its OpenAI partnership.

### Aider

Aider sits at ~41K GitHub stars (Apache 2.0). No single landmark release this week; version cadence averages multiple minor releases per week.

### OpenHands

- **OpenHands** — Active development (April–May 2026). Most recent stable release: v1.6.0 (March 30, 2026), covering pre/post action hooks and localization. Cloud platform at openhands.dev continues to operate alongside self-hosted CLI/GUI path. 68K GitHub stars, MIT license.

### SWE-agent

- **SWE-agent** — Ongoing (April 2026). Research-driven GitHub issue resolution agent from Princeton NLP. Configurable via YAML; reports state-of-the-art scores on SWE-bench variants. No major version release this cycle; active development continues on the main branch.

## Key Themes

- **GPT-5.5 resets the frontier API price point**: At $5/$30 per 1M tokens with a 1M context window, OpenAI positions GPT-5.5 directly against Claude Opus 4.7 ($5/$25), triggering the first direct price-tier head-to-head between the two leading commercial APIs since GPT-5.4.
- **DeepSeek V4 open-weights challenge the API cost floor**: Releasing 1.6T-param V4-Pro under MIT at preview pricing undercuts every closed competitor and maintains China's pattern of open-weight releases immediately following US flagship announcements.
- **Multimodal becomes table stakes**: Grok 4.3 (video), Nemotron 3 Nano Omni (video/audio/image/text), Gemini 3.1 (real-time voice/image), and Llama 4 (native multimodal MoE) all shipped within the same April window, signaling that text-only models are no longer competitive at the frontier tier.
- **Copilot as a model marketplace**: With GPT-5.5 and Claude Opus 4.7 both GA in Copilot's model picker within the same two-week window, GitHub Copilot is consolidating its position as the distribution surface where frontier model releases land fastest.
