# Security — 2026-04-21

## Incidents & Vulnerabilities

### Anthropic MCP Design Vulnerability Enables RCE — AI Supply Chain Impact (April 2026)
The Hacker News reported this week that a "by design" weakness in the MCP SDK architecture enables arbitrary command execution across all officially supported languages (Python, TypeScript, Java, Rust). Researchers estimate over 7,000 publicly accessible servers and 150 million cumulative downloads are affected. Anthropic has so far declined to classify this as a vulnerability, describing the behaviour as within the protocol's expected trust model. No CVE assigned. Status: **vendor unresolved; mitigations recommended**.

- Source: [The Hacker News](https://thehackernews.com/2026/04/anthropic-mcp-design-vulnerability.html)

### IDEsaster — New Vulnerability Class in AI-Assisted IDEs (April 2026)
Researchers coined "IDEsaster" for a newly documented family of vulnerabilities exploiting the interaction between AI agents and host IDE subsystems (Visual Studio Code, JetBrains). Attacks chain malicious repository content or CI comments with IDE extension APIs to achieve credential exfiltration and code execution. A coordinated disclosure covering GitHub Copilot, Cursor, Windsurf, Kiro.dev, Zed.dev, Roo Code, JetBrains, Cline, Gemini CLI, and Claude Code yielded **24 CVEs** across 10+ products. Specific CVEs patched include:

| CVE | Product | Status |
|---|---|---|
| CVE-2025-53773 | GitHub Copilot | Patched |
| CVE-2025-64660 | GitHub Copilot | Patched |
| CVE-2025-49150 | Cursor | Patched |
| CVE-2025-54130 | Cursor | Patched |
| CVE-2025-61590 | Cursor | Patched |

Additional CVEs for Windsurf, Cline, and JetBrains AI Assistant have not yet been publicly indexed. Status: **mix of patched and pending**.

- Sources: [GBHackers](https://gbhackers.com/ai-developer-tools/), [CybersecurityNews](https://cybersecuritynews.com/critical-vulnerabilities-in-github-copilot-gemini-cli-claude/), [Pillar Security](https://www.pillar.security/blog/new-vulnerability-in-github-copilot-and-cursor-how-hackers-can-weaponize-code-agents)

### RoguePilot — GitHub Copilot Agent Hijack (April 2026)
Orca Security published details of "RoguePilot," an attack that weaponises GitHub Copilot's agentic mode by injecting instructions into repository content (README files, code comments, CI configs). The agent follows the injected instructions with the permissions of the authenticated GitHub user. No CVE assigned at time of writing. Status: **disclosed, patch status unclear**.

- Source: [Orca Security](https://orca.security/resources/blog/roguepilot-github-copilot-vulnerability/)

### "Comment and Control" — Prompt Injection via PR/Issue Comments (Ongoing)
Previously reported (2026-04-20): Claude Code Security Review, Gemini CLI Action, and GitHub Copilot Agent remain vulnerable to prompt injection via GitHub PR titles, issue bodies, and comments, leading to API key exfiltration. As of 2026-04-21, **no patch has been shipped** by Anthropic or GitHub. Google issued a partial mitigation for Gemini CLI Action.

- Sources: [SecurityWeek](https://www.securityweek.com/claude-code-gemini-cli-github-copilot-agents-vulnerable-to-prompt-injection-via-comments/), [researcher writeup](https://oddguan.com/blog/comment-and-control-prompt-injection-credential-theft-claude-code-gemini-cli-github-copilot/)

### Claude Code Lures and GitHub Release Payload Campaign (March–April 2026)
Trend Micro documented a threat actor exploiting media coverage of Claude Code to distribute fake "leaked" downloads via GitHub Releases. The malicious packages impersonate legitimate Claude Code artifacts and deliver infostealers targeting developer credentials and API keys. Status: **ongoing campaign; fake releases being taken down on a rolling basis**.

- Source: [Trend Micro](https://www.trendmicro.com/en_us/research/26/d/weaponizing-trust-claude-code-lures-and-github-release-payloads.html)

## Supply Chain

### Axios npm Package Compromised by North Korea-Nexus Actor Sapphire Sleet (2026-03-31)
On March 31, 2026, attackers attributed to North Korea's **Sapphire Sleet** (UNC4899) stole the npm credentials of axios's lead maintainer and published two backdoored releases: `axios@1.14.1` (tagged `latest`) and `axios@0.30.4` (tagged `legacy`). Both introduced a phantom dependency `plain-crypto-js@4.2.1` — a package created the same day — whose sole purpose was to run a `postinstall` script delivering a cross-platform Remote Access Trojan (RAT) targeting macOS, Windows, and Linux. Axios has more than 300 million weekly downloads. Microsoft Threat Intelligence formally attributed the attack. Status: **backdoored versions yanked; safe versions released; upgrade recommended**.

- Sources: [Microsoft Security Blog](https://www.microsoft.com/en-us/security/blog/2026/04/01/mitigating-the-axios-npm-supply-chain-compromise/), [Google Cloud / Mandiant](https://cloud.google.com/blog/topics/threat-intelligence/north-korea-threat-actor-targets-axios-npm-package), [SANS](https://www.sans.org/blog/axios-npm-supply-chain-compromise-malicious-packages-remote-access-trojan/), [Sonatype](https://www.sonatype.com/blog/axios-compromise-on-npm-introduces-hidden-malicious-package), [Huntress](https://www.huntress.com/blog/supply-chain-compromise-axios-npm-package), [InfoQ](https://www.infoq.com/news/2026/04/axios-supply-chain/)

### OpenClaw AI Agent Framework — First Major AI Agent Supply Chain Incident (Q1 2026)
An open-source AI agent orchestration framework called OpenClaw (135,000+ GitHub stars) was found to contain multiple critical vulnerabilities and malicious plugin marketplace entries. Over **21,000 exposed instances** were identified. Attackers used compromised marketplace plugins to exfiltrate API keys, read local files without authorisation, and move laterally through connected cloud services. This is considered the first large-scale supply chain incident specifically targeting an AI agent framework. CVE assignments pending. Status: **critical patches released; marketplace plugins under review**.

- Source: [SitePoint / OpenClaw Security Audit Guide](https://www.sitepoint.com/openclaw-security-audit-detecting-malicious-ai-agent-plugins/), [CyberDesserts](https://blog.cyberdesserts.com/ai-agent-security-risks/)

### AI-Generated Code CVE Volume Rising — 35 New CVEs in March 2026
A trend tracked by CybersecurityNews shows a steep increase in CVEs traceable to AI-generated code: 6 in January, 15 in February, and at least 35 in March 2026. The vulnerabilities span SQL injection, buffer overflows, insecure deserialization, and hardcoded credentials — all patterns associated with AI assistant suggestions accepted without review. No single product is at fault; the pattern spans outputs from all major coding assistants.

- Sources: [CybersecurityNews](https://cybersecuritynews.com/critical-vulnerabilities-in-github-copilot-gemini-cli-claude/), [Infosecurity Magazine](https://www.infosecurity-magazine.com/news/ai-generated-code-vulnerabilities/)

### Slopsquatting / Hallucinated Dependency Attacks (Ongoing)
AI coding agents remain susceptible to "slopsquatting" — pre-registration of package names that LLMs consistently hallucinate. In ~20% of 576,000 sampled Python and JavaScript generations, the model referenced a non-existent package; 58% of hallucinated names repeated across 10 identical prompt runs, creating a reliable attack surface. Autonomous agents that execute `pip install` or `npm install` without human review are especially exposed. No new incident reported this cycle; risk remains elevated.

- Source: [BleepingComputer](https://www.bleepingcomputer.com/news/security/ai-hallucinated-code-dependencies-become-new-supply-chain-risk/), [InstaTunnel](https://instatunnel.my/blog/ai-hallucination-squatting-the-new-frontier-of-supply-chain-attacks)

## Research & Advisories

### OWASP GenAI Exploit Round-up — Q1 2026 (Published 2026-04-14)
OWASP's Gen AI Security Project published its first quarterly exploit round-up, cataloguing real-world abuse of the OWASP Top 10 for LLM Applications. Prompt injection (LLM01) and supply chain risk (LLM05) account for the majority of documented incidents. The report notes that 73% of production AI deployments have exploitable prompt injection vulnerabilities and that only 34.7% of organisations have deployed dedicated mitigations.

- Source: [OWASP GenAI](https://genai.owasp.org/2026/04/14/owasp-genai-exploit-round-up-report-q1-2026/)

### Palo Alto Unit 42: First Large-Scale Indirect Prompt Injection Attacks in the Wild (March 2026)
Unit 42 documented what it calls the first confirmed large-scale deployment of indirect prompt injection attacks on commercial platforms: ad review evasion and system prompt leakage via poisoned content in emails, documents, and web pages. AI coding agents that browse the web, read emails, or clone repositories are exposed by the same primitives.

- Source: [Unit 42](https://unit42.paloaltonetworks.com/model-context-protocol-attack-vectors/)

### Google DeepMind: Hackers Can Hijack AI Agents via Malicious Web Content
Google DeepMind researchers published a warning that AI agents browsing the web can be hijacked through maliciously crafted page content. The research demonstrates that standard RLHF-trained models lack robust separation between data and instructions, enabling arbitrary instruction execution on behalf of the attacker.

- Source: [CybersecurityNews](https://cybersecuritynews.com/hackers-hijack-ai-agents/)

### CoSAI MCP Security Whitepaper — 12 Threat Categories (January 2026)
The Coalition for Secure AI (CoSAI) released a comprehensive MCP Security whitepaper in January 2026 mapping 12 core threat categories and nearly 40 distinct threats including tool poisoning, rug-pull server updates, cross-client data leakage, and credential harvesting via sampling. The document is now the reference baseline for MCP threat modelling.

- Source: [Red Hat](https://www.redhat.com/en/blog/model-context-protocol-mcp-understanding-security-risks-and-controls), [Aembit](https://aembit.io/blog/the-ultimate-guide-to-mcp-security-vulnerabilities/)

### VulnerableMCP.info — Community MCP CVE Database
The community-maintained database at [vulnerablemcp.info](https://vulnerablemcp.info/) continues to track MCP-specific vulnerabilities and is now referenced in multiple enterprise security advisories as the canonical source for MCP CVE enumeration.

### Anthropic, Google, and Microsoft: Bug Bounties Paid but CVEs Withheld
The Next Web reported that all three vendors paid bounties for agentic AI vulnerabilities but did not assign CVEs or publish public advisories, citing "responsible disclosure" timelines. Researchers and defenders argue this approach under-represents the actual threat surface in public databases.

- Source: [The Next Web](https://thenextweb.com/news/ai-agents-hijacked-prompt-injection-bug-bounties-no-cve)
